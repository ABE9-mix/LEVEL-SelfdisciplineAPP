# 视觉风格 · NES 12-bit（像素复古）

> 本文是 `FIG/nes12` 的风格说明书兼**组件绘制清单**。所有尺寸与色值都从 `core.mjs` / `widgets.mjs` / `build.mjs` 静态抽取（脚本 `_inventory.mjs`），不是回忆值。
> 画布单位：**1 设计像素 = 1 游戏像素**，原生分辨率 **256 × 240**。

---

## 0. 一句话风格

**12px 像素字体 + 蓝黄双色体系 + NES 硬边倒角 + 抖动过渡**：用 8-bit 的语法（有限调色板、1px 描边、无抗锯齿、抖动代替渐变），去表达一个现代 App 的组件（横向色块滑动标签、抽屉、进度环、徽章）。

---

## 1. 起源与三条铁律

| 序号 | 铁律 | 落地方式 |
|---|---|---|
| ① | **有限调色板** | **14 色**封顶（见 §2），任何新颜色必须先加进 `P` 并同步 `audit.mjs` 的 `PALETTE` 集合，否则自检报"板外色" |
| ② | **零抗锯齿** | 只用矩形与整数坐标路径；文本用像素字模（`Ark Pixel 12px Mono`，12px 下渲染为纯二值：孤立测试只有 2 色、零过渡色） |
| ③ | **硬边倒角** | 不用圆角、不用 blur；"圆"感靠 **1px 亮边（上+左）+ 1px 暗边（下+右）+ 1px 黑描边** 的斜角假象 |

## 2. 调色板（14 色 · 实测 RGB，另加 8 个画面专用场景色，可选）

### 2.1 主色（蓝黄体系）

| 令牌 | 色值 | 用途 | 面积占比（经验） |
|---|---|---|---|
| `ink` | `#0b0b14` | 1px 外描边、遮罩、暗处 | 20–30% |
| `body` | `#2b4c9b` | 按钮底、标题条、名牌 | **主色 55%** |
| `hi` | `#6c9be0` | 亮边（上+左）、次级文字 | 8% |
| `lo` | `#16264e` | 暗边（下+右）、阴影面 | 8% |
| `txt` | `#ffffff` | 一级文字 | 5% |
| `gold` | `#ffd34e` | **强调色**：选中、光标、数值、快捷键 | **8%（不超过）** |

> **蓝黄关系**：蓝（`body`）承担"可点击的实体"，黄（`gold`）承担"当前焦点"。二者**永不同面积**：黄只出现在小面积（光标 8×8、选中条、数字），避免整屏发光。

### 2.2 状态色（禁用）

| 令牌 | 色值 | 说明 |
|---|---|---|
| `dis` / `disHi` / `disLo` | `#3a3a44` / `#5c5c68` / `#22222a` | 禁用底 / 亮边 / 暗边（斜面收平） |
| `disTxt` | `#7a7a86` | 禁用文字与浅色辅助字 |

### 2.3 面板色（凹窗）

| 令牌 | 色值 | 说明 |
|---|---|---|
| `winBody` / `winHi` / `winLo` | `#16162a` / `#3a3a5c` / `#0a0a12` | 窗口底 / 亮边 / 暗边 |

### 2.4 选中色

| 令牌 | 色值 | 说明 |
|---|---|---|
| `selBody` | `#4a3a10` | 选中条底（暗金） |
| `selHi` | `#ffd34e` | 选中条（与 `gold` 同值，语义分离） |
| `selTxt` | `#ffd34e` | 选中文字 |

### 2.5 场景色（画面专用，共 6 色）

| 色值 | 用途 |
|---|---|
| `#101828` | 夜空 |
| `#0a2010` | 草地 |
| `#1c5c2c` | 草地高光边（2px） |
| `#4a2c14` | 木屋/宝箱 |
| `#7a2020` | 屋顶/箱盖 |
| `#e04040` | 生命值（红心） |

用色顺序：背景 → 面板 → 实体 → 焦点 → 文字。

## 3. 字体与网格（实测度量）

| 项目 | 值 | 证据 |
|---|---|---|
| 字体 | `Ark Pixel 12px Mono zh-Hans`（OFL 1.1） | 本机已安装，FigCraft 通过系统字体读取 |
| 字号 | **12 px** | — |
| 汉字 / 全角标点 / 箭头推进 | **12 px** | `"开"=12 "开开"=24 "开始游戏"=48` |
| 拉丁 / 数字 / 半角空格推进 | **6 px** | `"A"=6 "AB"=12 "A1"=12` |
| TEXT 节点高 | **12 px** | — |
| 墨点纵向范围 | 节点顶 **+1 … +11**（11 行） | 放 y=0 与 y=20 墨带落在 `1..11` / `21..31`，零漂移 |
| 行距 | **12 px** | 段落与多行文本一致 |
| 渲染 | **纯二值**，零过渡色 | 孤立测试截图只有 `#000000` / `#ffffff` |

**结论**：宽度全部由实测字宽反推，**没有取整误差**。按钮 **128 × 24** = 左右各 16 + 96（8 个汉字）；高 24 = 上下各 6 + 12 字高。

## 5. 组件绘制清单（共 **24 类**：13 个导出函数（含 2 个底层工具）+ 1 个私有 + 7 组画面部件 + 3 个光标指示）

### 5.1 原子图形（3 类）

| # | 组件 | 函数 | 尺寸 | 状态 | 绘制要点 |
|---|---|---|---|---|---|
| A1 | 像素矩形 | `v()` | 任意 | 1 | `M x y L …` 四点多边形，1 设计像素 = 1 像素 |
| A2 | 描边环（外框） | `ring(x,y,w,h,t)` | 任意，t=1 | 1 | 外圈**正向** + 内圈**反向**（FigCraft 用 nonzero 填充，同向不会挖空） |
| A3 | 单像素点阵 | `cells(pts)` | 每点 1×1 | — | 图标/光标用；一段 path 里拼接多个 1×1 方块 |

### 5.2 容器（2 类）

| # | 组件 | 函数 | 参数 | 结构 |
|---|---|---|---|---|
| B1 | 凹窗（JRPG 窗） | `win()` | `x y w h body hi lo name` | 4 层：底 → 顶部/左 1px 亮边 → 底部/右 1px 暗边 → 1px 黑环 |
| B2 | 凸起斜面 | `bevel()` | `x y w h body hi lo glint` | 5 层：底 → 亮边 → 暗边 → **内嵌高光**（上+左再内缩 1px）→ 1px 黑环 |

> 凹 = 暗边在外、亮边在内；凸 = 亮边在外、暗边在内。二者**只靠这 4 条 1px 线的顺序区分**，不加圆角。

### 5.3 交互控件（7 类 + 1 私有）

| # | 组件 | 函数 | 默认尺寸 | 状态数 | 说明 |
|---|---|---|---|---|---|
| C1 | 菜单按钮 | `button()` | **128 × 24** | **4**（default / hover / active / disabled） | hover 只换字色（白→金）；active 反白（金底黑字）并**内容下移 1px**；disabled 斜面收平；可挂 `cursor`（▶ 占 6+6 px，标签在剩余宽度内居中） |
| C2 | 列表行 | `row()` | 宽 × **20** | 3（普通 / 选中 / 带快捷键） | 选中 = 金底 + 1px 黑环 + ▶ 光标（x+6）+ 黑字；快捷键列右对齐，选中时也是黑字 |

## 6. 新特性：用复古语法覆盖现代组件

这一版的核心不是"做成复古游戏"，而是**用 8-bit 的语法去画现代 App 才有的组件**。三条具体规则：

### 6.1 横向色块滑动标签（Segmented / Tabs）

现代实现是"胶囊 + 平滑位移"。复古画法：

```
[ 底色槽 16 高 · ink ]  [ 选中块 = gold 实心，1px ink 环 ]  [ 未选项 = 透明，仅文字 ]
```
- **不做圆角**，靠 1px 环把"当前块"从槽里"顶"起来；
- 选中块宽度 = 标签字宽 + 8，两侧各留 4 给未选项；
- 滑动感用**位移 1px 的错位**表达（相邻选中态错 1px），不做补间。

### 6.2 抖动填充（Dither）替代一切渐变

| 场景 | 图案 | 密度 | 说明 |
|---|---|---|---|
| 遮罩 / 变暗 | 2×2 棋盘 | 50% | 只用 `ink` 一色，靠密度控制明度 |
| 天空 → 地面过渡 | 逐行收窄的棋盘带 | 100→0% | 每 2 行减 1 格，形成 8 级台阶 |
| 面板底纹（可选） | 25% / 12.5% 稀疏点 | 稀疏 | 只用于强调"不可交互区" |

**禁忌**：任何 blur、任何 alpha 渐变、任何超过 2 色的抖动。

### 6.3 状态用"位移 + 反白"，不用阴影

| 状态 | 语义 | 视觉动作 |
|---|---|---|
| 常态 | 可点 | 蓝底白字 + 完整斜面 |
| 悬停 | 可点（当前） | **只换字色**：白 → 金 |
| 按下 | 已触发 | **底反白**（金底黑字）+ 内容下移 1px + 去掉内嵌高光 |
| 禁用 | 不可点 | 底/边全部降饱和（灰系）+ 斜面收平 + 文字 `disTxt` |

## 9. 自检口径（改颜色/加组件时必须跑）

```bash
cd figcraft_mcp/pixel/nes12
node build.mjs && node export-assets.mjs && node audit.mjs && node sheet.mjs
```

判据：

```
零越界（每卡余 -8 对称）
零重叠 / 全整数坐标
板外色 = 0（调色板之外的颜色，逐卡 1:1 截图比对）
文本边缘过渡像素 ≤ 0.1%（FigCraft 光栅器行为，非设计缺陷）
```

## 10. 与本项目另外两套稿子的接力关系

| 稿子 | 尺寸 | 语言 | 什么时候用 |
|---|---|---|---|
| `FIG/iphone390`、`FIG/iphone390-ABC` | 390 × 844 | 9 级中性灰线框 | 先定信息架构、流程、排版骨架 |
| **`FIG/nes12`（本文）** | 256 × 240 | 14 色 NES 复古 | 定稿视觉：把线框里的每个方块换成像素图形 |

**交接规则（线框图 → 像素稿）**：

| 线框元素 | 像素稿对应 | 换算 |
|---|---|---|
| 390 宽安全边距 16 | 256 宽安全边距 8 | 约 0.65×，但**不复用比例**，按 8 的整数倍重排 |
| 主按钮 358×52 | 菜单按钮 128×24 | 像素稿按「8 个汉字 + 16 边距」重算，不看线框宽度 |
| 列表行 60 高 | 列表行 20 高 | 20 = 4 + 12 + 4 |
| 卡片圆角 12 | **圆角 0** | 像素稿一律直角，靠 1px 亮/暗边做出"斜角" |
| 虚线框 = 可选机制 | 虚线 = `dashes:[5,4]` 的 1px 环 | 语义不变 |
| 占位方块 24×24 | 16×16 像素图标 | 见 §7.3 待画清单 |
| 半透明遮罩 | **2×2 棋盘点阵** | 像素稿禁用 alpha |

> 一句话：**线框决定"放什么"，像素稿决定"长什么样"**；两套的数字不互算，只共用语义（哪些是按钮、哪些是可选项、哪些是状态）。
