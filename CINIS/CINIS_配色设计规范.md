# LEVEL 游戏化自律 App｜配色设计规范

> **视觉概念：现代效率美学 × 魂类世界观 × 成长仪式感**  
> **核心体验：点燃行动，直面挑战，见证成长。**  
> 品牌口号建议：**IGNITE YOUR DAY.**

---

## 1. 配色设计目标

LEVEL 不是把普通待办清单简单涂成游戏风格，而是通过有层次的色彩系统，分别支持日常行动、挑战投入和成就反馈。

- **日常使用：** 清晰、现代、有能量，帮助用户快速进入行动状态。
- **旅者模式：** 稳定、自然、低压力，强调持续积累。
- **骑士模式：** 温暖、坚毅、有锻造感，强调主动迎接挑战。
- **深渊模式：** 深邃、未知、高风险，强调稀缺资源与挑战代价。
- **完成反馈：** 即时反馈鲜明，阶段奖励具有仪式感，长期成长以真实数据呈现。

整体采用**中性基础色 + 品牌蓝 + 有语义的模式强调色**。魂类氛围主要通过深色空间、局部光效、克制的纹理与反馈动效实现，不依赖满屏特效或大量装饰。

### 基础界面使用建议

- 日常首页、目标、任务、成长数据页以浅色主题为主。
- 蓝色用于最重要的操作、选中导航和关键进度，不要让每个图标与按钮都使用主蓝。
- 页面结构优先依靠间距、排版、分割线与卡片层级表达，不用大量阴影制造层级。
- 以上色值是初始设计令牌；进入 Figma 后仍需检查文字对比度、控件状态和不同亮度屏幕上的表现。

| `Accent/Achievement` | `#F5C66A` | 成就、稀有奖励、阶段结算 | 等级提升、里程碑、徽记与结算高光 |
| `Growth/Positive` | `#287D68` | 稳定进步、正向状态 | 成长趋势、已完成状态的辅助表达 |
| `State/Danger` | `#FF3158` | 风险、失落、不可逆代价提示 | 深渊风险提示、奖励失落、失败状态 |
| `Neutral/Challenge-BG` | `#151B28` | 挑战空间 | 挑战页深色背景 |
| `Neutral/Challenge-Surface` | `#252D3A` | 深色卡片与面板 | 挑战页内容承载层 |

### 奖励色彩规则

1. **橙色用于即时奖励**：每次完成任务时，反馈清晰但不必过度炫目。
2. **金色用于稀有时刻**：阶段结算、重要徽记、等级突破时才突出显示。
3. **危险红用于风险信息**：不要把红色泛用于所有普通按钮，否则会削弱风险语义。
4. **永久成长与暂存奖励必须在文案和视觉上区分**：颜色只能辅助表达，不能代替文字规则。

## 4. 三种挑战模式配色

三个模式共享相同的信息架构、组件结构和排版规范；仅通过模式强调色、背景氛围、图标和状态文案区分，避免变成三个互不相关的 App。

### 4.1 旅者模式｜TRAVELER

**关键词：** 稳定、探索、恢复、低压力  
**模式主色：** `#287D68` 森林青绿

| Token | HEX | 用途 |
|---|---|---|
| `Mode/Traveler` | `#287D68` | 模式标识、选中边框、进度强调 |
| `Mode/Traveler-Soft` | `#E5F3EE` | 浅色模式卡片、轻提示背景 |
| `Mode/Traveler-Dark` | `#174F43` | 深色文本或图标强调 |

**视觉建议：**
- 以浅背景和自然的青绿色点缀为主。
- 视觉轻盈，突出计划调整、持续行动与稳定成长。
- 不使用大量发光、火焰或危险符号。
- 语义：允许用户建立节奏，重点是持续而不是惩罚。

### 4.2 骑士模式｜KNIGHT

**关键词：** 锻造、意志、荣誉、承担风险  
**模式主色：** `#F0AD53` 熔炉琥珀

| Token | HEX | 用途 |
|---|---|---|
| `Mode/Knight` | `#F0AD53` | 模式标识、挑战进度、魂火强调 |
| `Mode/Knight-Soft` | `#FFF1D8` | 浅色提示、模式卡片辅助背景 |
| `Mode/Knight-Dark` | `#8A4B12` | 需要较高对比度的文字、图标 |

**视觉建议：**
- 使用深炭灰或深褐色承载挑战内容，琥珀色作为局部光源。
- 让“锻造、火焰、荣誉”的意象通过徽记、线条和局部光效表达。
- 普通任务反馈不要每次都使用大面积金光；把强反馈留给阶段胜利。
- 语义：挑战由用户主动选择，奖励与风险规则在开始前明确告知。

### 4.3 深渊模式｜ABYSS

**关键词：** 未知、压迫、危险、孤注一掷  
**模式主色：** 虚空黑 `#080910` + 裂隙紫 `#8B5CF6` + 猩红 `#FF3158`

| Token | HEX | 用途 |
|---|---|---|
| `Mode/Abyss-Background` | `#080910` | 深渊模式主背景 |
| `Mode/Abyss-Surface` | `#17111F` | 卡片、弹层、信息面板 |
| `Mode/Abyss-Energy` | `#8B5CF6` | 裂隙能量、挑战进度、特殊资源 |
| `Mode/Abyss-Danger` | `#FF3158` | 风险、失落状态、关键警告 |
| `Mode/Abyss-Anomaly` | `#D6FF3F` | 极少量异常高亮，仅用于稀有提示或特殊奖励 |
| `Mode/Abyss-Text` | `#E9E3F0` | 主文字 |
| `Mode/Abyss-Text-Secondary` | `#B8B0C5` | 次级文字，仍需检查对比度 |

**视觉建议：**
- 以虚空黑和深紫黑构建空间；紫色代表深渊能量，猩红只在风险真正发生或需要用户注意时出现。
- 荧光黄绿是可选的艺术点缀色，面积极小，不应与紫色、红色争夺主视觉。
- 使用局部裂隙光、微弱噪点、边缘发光和克制的动态反馈营造不稳定感；避免满屏霓虹，防止变成赛博朋克风格。
- 在深渊模式中，风险不能只靠红色表达；必须同时展示清晰的风险说明、剩余暂存奖励和中断后的结果。
- 语义：强调挑战的高风险，但不制造信息不透明或误导。

### 三种模式快速对照

| 维度 | 旅者 | 骑士 | 深渊 |
|---|---|---|---|
| 核心色彩 | 森林青绿 | 熔炉琥珀 | 虚空黑、裂隙紫、猩红 |
| 情绪 | 平静、可持续 | 坚毅、热烈 | 压迫、未知、高风险 |
| 背景策略 | 浅色为主 | 深色搭配暖光 | 深色为主，强对比局部高亮 |
| 光效强度 | 很低 | 中等、集中 | 较强但范围受控 |
| 红色使用 | 通常不需要 | 仅风险状态 | 专门表达危险与失落 |
| 金色使用 | 少量奖励 | 荣誉与结算 | 主要保留给成功结算时的反差 |

## 5. 页面情绪与配色映射

| 页面／状态 | 主导颜色 | 反馈强度 | 设计目的 |
|---|---|---|---|
| 今日首页 | 浅灰白 + 品牌蓝 | 低至中 | 清晰、清醒、迅速开始行动 |
| 创建目标／任务 | 浅灰白 + 品牌蓝 | 低 | 降低操作负担 |
| 专注执行 | 中性背景 + 少量模式色 | 低 | 减少视觉干扰，维持专注 |
| 普通任务完成 | 品牌蓝 + 魂火橙 | 中 | 让用户立即感知行动已记录 |
| 阶段目标达成 | 深色底 + 成就金 | 高 | 强化里程碑的仪式感 |
| 旅者挑战 | 青绿 | 低至中 | 稳定、轻量 |
| 骑士挑战 | 炭灰 + 琥珀 | 中 | 坚定、投入、锻造感 |
| 深渊挑战 | 虚空黑 + 裂隙紫，危险时用猩红 | 中至高 | 高风险、未知、强烈对比 |
| 挑战中断 | 对应模式底色 + 风险色 | 高但克制 | 说明发生了什么与下一步选择 |
| 成长总览 | 浅底 + 品牌蓝 + 少量成就金 | 低至中 | 让长期进步清晰可读 |

## 6. 任务反馈与成就仪式

建议建立三级反馈，不要让每次打卡都使用最高强度的视觉效果。

### Level 1：即时反馈
- 颜色：品牌蓝 + 魂火橙。
- 内容：任务完成状态、获得经验、魂火变化、目标进度更新。
- 动效：短暂的数字递增、进度条推进或魂火亮起。
- 原则：快速明确，不打断用户继续行动。

### Level 2：阶段成就
- 颜色：深色背景 + 成就金。
- 内容：阶段目标达成、徽记解锁、等级提升或挑战结算。
- 动效：较明显但短暂的光效、徽记显现或结算动画。
- 原则：与普通反馈拉开差距，让重要成果更有分量。

### Level 3：真实成长
- 颜色：浅色数据面板 + 品牌蓝，关键里程碑辅以成就金。
- 内容：完成次数、执行时长、阶段变化、长期趋势和目标成果。
- 动效：尽量克制，优先保证图表和数据可读性。
- 原则：虚拟等级不能替代真实成长证据。

## 7. 现代美学与视觉控制规则

### 7.1 色彩比例

可从以下比例开始测试，而不是把它当成硬性规定：

- **70% 中性色：** 背景、卡片、正文与结构。
- **20% 品牌色／模式色：** 主要操作、进度、当前模式。
- **10% 情绪强调色：** 魂火橙、成就金、风险红等。

深渊模式可以采用更高比例的深色背景，但紫色、红色和荧光色仍应局部使用。

### 7.2 现代感的关键

- 通过留白、网格、排版和信息层级建立秩序，不依赖大量装饰。
- 圆角、边框、阴影与图标风格在三个模式之间保持一致。
- 发光效果集中在魂火、挑战进度、重要奖励等少量核心元素。
- 深色挑战页不等于所有页面都使用深色；日常任务页应保持清爽。
- 避免同时使用大面积渐变、强烈噪点、金属纹理、粒子和粗重描边。

### 7.3 可访问性与状态语义

- 不能仅靠颜色区分成功、失败或模式；同时使用文字、图标、形状或状态标签。
- 小字号文字、按钮文字与背景需要做对比度检查。
- 浅色背景上的金色、橙色通常更适合用于图形或较大元素；小字优先使用通过对比度检查的深色。
- 深色背景上的紫色与红色应检查文字可读性，必要时用浅色文字呈现说明。
- 错误、危险与奖励颜色应保持语义一致，避免同一种颜色在不同页面代表相反状态。

## 9. 线框与高保真的实施顺序

1. **低保真阶段：** 先确定页面结构、信息层级和交互流程，不必过早加入完整的魂类视觉。
2. **中保真阶段：** 应用品牌基础色，检查按钮、卡片、导航和状态组件是否统一。
3. **高保真阶段：** 加入三种模式的专属色、魂火与徽记视觉、局部发光和阶段结算动效。
4. **可用性测试：** 观察用户能否快速区分三种模式、理解风险规则，并正确辨认永久成长与暂存奖励。
5. **视觉校验：** 检查对比度、色彩一致性、不同屏幕亮度和色觉差异下的可读性。

## 10. 最终设计原则

LEVEL 的配色不是为了让每一页都“很燃”，而是为了让不同阶段产生不同的情绪：

- **打开 App：** 品牌蓝唤起行动，界面清晰有秩序。
- **进入挑战：** 模式色建立不同的心理预期。
- **完成任务：** 魂火橙提供即时反馈。
- **阶段胜利：** 成就金制造仪式感与稀缺感。
- **面对深渊：** 虚空黑、裂隙紫和猩红建立未知、危险与高风险的视觉张力。
- **回顾成长：** 以清晰的数据和真实记录证明长期积累。

> **核心原则：日常界面保持清晰，挑战界面强化情绪，重要成就才释放强烈的视觉反馈。**

这套配色是 LEVEL 的第一版视觉方向。进入高保真原型后，应通过实际页面、对比度检查和用户测试进行微调。
