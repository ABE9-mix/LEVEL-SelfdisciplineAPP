## 五、踩坑

| 现象 | 正解 |
|---|---|
| `component instantiate` 传 COMPONENT_SET | 报 `no-mutation`，必须传具体变体的 COMPONENT id |
| `-x/-y` 当成画布坐标 | 它是父级局部坐标，不要加屏原点，否则实例散落到屏外 |
| `node set --fill` / `--stroke` 对部分色值必回滚 | 改走 `node bind`（`-c` 传集合名称）或 PAINT / EFFECT 样式加 `--field fill` |
| 实例内子节点 id 是 `I实例id;源id` | `set-text` 无效，文案必须靠组件 TEXT 属性 + `component prop set` |
| 正则里 `(?:...)` 不计数 | 组号要数清楚，解析后先断言再批量 |
| 截图 `pixelWidth` 不等于 `nodeWidth × scale` | 说明混入相邻屏，要单屏截图或先核对宽度 |
