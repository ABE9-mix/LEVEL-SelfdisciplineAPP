# 05 · 知识与彩蛋

> 两条纪律：知识是奖励，不是课程——用户完成现实动作后顺手收获；
> 每个数字都会被用户去查——准确性是产品责任，不是文案水平问题。

## 一、知识卡数据规范
| 字段 | 必填 | 约束 | 例 |
|---|---|---|---|
| `id` | 是 | 系列-序号 | `PLA-014` |
| `title` | 是 | ≤16 字，反直觉，读完想说给别人听 | 金星上一天比一年长 |
| `body` | 是 | ≤120 字，含 1 个具体数字 | 金星自转一圈约 243 个地球日，公转只要约 225 个 |
| `number` | 是 | 核心数字，单独抽出供大号显示 | 243 天 > 225 天 |
| `series` / `tier` | 是 | 6 系列之一 / T0–T3 | PLA / T2 |
| `source` / `verified_at` | 是 | 权威来源名 + 核对日期；超 24 个月进复核队列 | NASA 行星事实表 / 2026-02 |
| `extend` / `keywords` | 否 | 延伸方向 / 3–5 个关键词 | 查：金星大气压是地球的 92 倍 |

## 六、内容生产与质检
| 环节 | 要求 |
|---|---|
| 撰写 | 单卡 ≤40 分钟（查证 15–25 + 撰写 10 + 核对 5） |
| 核对 | 双人独立核对；两人对数字来源必须一致，不一致退回 |
| 来源 | 每条写可核查的机构名或数据集名，不写「网上说」 |
| 语言 | 不用「科学家发现」「最新研究称」等模糊主语；不用叹号与「震撼」「惊人」 |
| 争议题 | 前沿争议（哈勃常数张力、银河系直径、宇宙年龄差异）必须写区间与「仍在修订」 |
| 错误率红线 | 抽查错误率 >0.5%（200 张里超过 1 张）→ 暂停发新卡，全面复核 |

## 九、扰动负面清单
| 不做 | 原因 |
|---|---|
| 限时活动、连续签到翻倍 | 制造 FOMO 与义务 |
| 稀有物可购买、分享才能解锁 | 破坏「知识是奖励」逻辑，社交绑架 |
| 暗箱概率、稀有度影响任务判定 | 概率一律公开，随机不改变难度 |
| 稀有物过期消失、未抽到的沮丧动画 | 已获得的东西永不收回；T1 保持平静 |
## 十、现实联动
- 星图可点：动态星空约 300 颗真实亮星可点，点开对应知识卡。
- 观测日历：按经纬度提示 ISS 过境与流星雨高峰，只提示、不打卡。
- 延伸方向：卡内 `extend` 关键词一点复制到剪贴板；不做外链跳转、内嵌文章与 AI 问答。
