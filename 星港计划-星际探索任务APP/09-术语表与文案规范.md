# 09 · 术语表与文案规范

> 本文是**写作的唯一真相源**。任何界面文本在落地前都要过三关：术语一致、语气合规、长度达标。

---

## 一、术语对照表（世界词 ↔ 现实词）

### 1.1 界面用词原则

**同一个概念，界面上永远只用一种说法。** 世界词只在"氛围位置"（动效、结算标题、氛围句）出现；功能位置（按钮、设置项、表单标签）一律用现实词。

| 概念 | ✅ 界面用词（功能位） | ✅ 氛围用词（氛围位） | ❌ 不用 |
|---|---|---|---|
| 专注计时 | 开始专注 / 番茄钟 | 点火 | 开火、发动、启动引擎 |
| 计时完成 | 完成 / 达标 | 入轨 | 抵达、通关、胜利 |
| 早起闹钟 | 闹钟窗口 / 提醒 | 发射窗口 | 起床任务、出征 |
| 提醒时间到 | 到点 | 窗口过境 | 发射、起飞 |
| 经验值 | 推进值 / XP | 推进值 | 星币、能量、燃料值 |
| 知识卡 | 研究成果 / 卡片 | 研究成果 | 教材、课程、资料 |
| 永久记录 | 记录 / 历史 | 星图 | 档案库（易与档案馆混） |
| 阶段挑战 | 阶段挑战 | 远征 | 关卡、副本、Boss |
| 随机彩蛋 | 随机彩蛋 / 随机事件 | 扰动 | 抽奖、宝箱、掉落 |
| 暂停机构 | 暂停 | 停机 | 关闭、解散、废弃 |
| 删除机构 | 归档 | — | 销毁、抹除 |
| 机构 | 机构 / 部门 | 机构 | 组织、团队、公会 |
| 机构建筑 | 设施 | 设施 | 建筑（口语可以，表单里用"设施"） |
| 星球主界面 | 星球地图 | 星球 / 星港 | 世界、家园、基地 |
| 引导 AI | 决策 AI | 决策 AI | 助手、管家、NPC、机器人 |
| 光照状态 | 光照明暗 / 时段 | 相位（晨/昼/昏/夜/深夜） | 天气、季节（除非真做季节） |
| 地图弹窗 | 面板 | 舱窗面板 | 弹窗、详情页 |

### 1.2 必须消失的词（前案遗留）

| 旧词 | 新词 | 原因 |
|---|---|---|
| 领航员 | **决策 AI** | 已改为有判断、可建议的调度智能（见 02 §3.2） |
| 轨道空间站 | **小星球 / 星港地表** | 设定已改为"停泊在小星球上"（世界事实 E） |
| 今日页 | **今日列表**（地图形态下为副视图） | 主界面已是星球地图 |
| 星港页 | **星球地图**（设施即入口） | 不再单开养成页 |

## 二、三个语气来源（谁在说话）

| 来源 | 场景 | 规范 |
|---|---|---|
| **决策 AI** | 引导、状态、建议、吐槽 | 有人味的副手；先判断后建议；短吐槽每日 ≤2 次；有配额 |
| **观测台** | 数字页、周报、知识卡署名 | 只报数，不下判断；纯陈述句 |
| 无署名 | 静默场景 | 不出现任何评价 |

**四个禁止**：

| 禁止 | 原因 |
|---|---|
| ❌ 恭维（你太棒了、真厉害） | 不做情绪评价 |
| ❌ 空鼓励（加油、坚持就是胜利） | 无信息量 |
| ❌ 恐吓（中断 3 天、前功尽弃） | 不把中断变成负债 |
| ❌ 承诺（30 天改变人生、脱胎换骨） | 不承诺结果 |

## 三、长度规范

| 位置 | 上限 | 依据 |
|---|---|---|
| HUD 一句话（决策 AI） | **18 字**（1 行）/ 36 字（2 行） | HUD 宽 358，15pt 字体 |
| 按钮 | **8 汉字**（96 pt） | 128 pt 按钮左右各留 16 |
| 面板标题 | 12 字 | 面板头空间 |
| 任务名 | 20 字（输入上限） | 列表行单行截断 |
| 机构名 | 12 字 | 地图标签引线宽度 |
| 星球名 | 12 字 | 主界面标题 |
| 知识卡标题 | 16 字 | 卡面大标题 |
| 知识卡正文 | **120 字** | 一屏可读完，不滚动 |
| 提示 / Toast | 18 字 | 单行 |
| 周报结论句 | 24 字 | 单行 |
| 设施铭牌 | 10 字 | 三维模型上的装饰层 |

**校验方式**：中文按 1 字 = 1 单位、拉丁与数字按 0.5 单位计（390 宽 × 15pt 下的近似）；超过上限的文案由校核脚本报错。

| 词 | 允许场景 |
|---|---|

## 七、文案校核脚本（可落地）

```js
// 中文 1 单位 / 拉丁与数字 0.5 单位，按 15pt 字体估宽
const width = (s) => [...s].reduce((w, c) => w + (c.codePointAt(0) < 0x2e80 ? 0.5 : 1), 0);

const LIMITS = {
  hud_line: 18, btn: 8, panel_title: 12, mission: 20,
  agency: 12, planet: 12, card_title: 16, card_body: 120,
  toast: 18, weekly: 24, plate: 10,
};

const BANNED = ['征服','占领','开拓','殖民','打败','战胜','消灭','击杀','干掉',
  '血量','满血','暴击','抽奖','宝箱','掉落','太棒','真棒','棒极了','加油',
  '坚持就是胜利','你可以的','拖延症','懒惰','前功尽弃','荒废','白费','浪费',
  '排行榜','排名','击败','垫底','拖后腿','改变人生','逆袭','脱胎换骨','蜕变',
  '星币','金币','钻石','代币','充值'];

const errors = [];
for (const [slot, text] of COPY_ITEMS) {
  const w = width(text), max = LIMITS[slot];
  if (!max) errors.push(`未知槽位 ${slot}：${text}`);
  else if (w > max) errors.push(`超长 [${slot}] ${w} > ${max}　「${text}」`);
  for (const b of BANNED)
    if (text.includes(b)) errors.push(`禁词「${b}」：${text}`);
  if (text.includes('！')) errors.push(`叹号：${text}`);
  if (/[\u{1F300}-\u{1FAFF}\u{2600}-\u{27BF}]/u.test(text)) errors.push(`emoji：${text}`);
}
console.log(errors.length ? errors.join('\n') : `通过：${COPY_ITEMS.length} 条`);
```

**用法**：把 §四 的所有文案录进 `COPY_ITEMS`（`[槽位, 文本]` 数组），跑一遍；**报错为 0 才允许进设计稿**。设计稿中的新增文案同样要过一遍。
