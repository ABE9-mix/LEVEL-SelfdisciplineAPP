# 07 · 信息架构与界面规范

> **本版已按「三维星球地图为主 + 今日列表一键切」重构。** 三维规格（相机、球体、光照、设施、HUD、舱窗面板、性能）见 [10-星球地图与三维场景](10-星球地图与三维场景.md)。

---

## 一、导航结构（4+1）

```
【主界面】   三维星球地图  ⇄  今日列表（视图开关，同一路由）
              │
              └── 中央主按钮「开始专注」（悬浮，永远可达）

【底栏二级】  今日  ·  星图  ·  复盘  ·  我的        （4 个图标 + 中央主按钮 = 4+1）

【面板层】    设施面板 L1 → 计划面板 L2 → 任务面板 L3     （舱窗内推入，最多 3 层）
【模态层】    计时页 / 闹钟窗 / 结算 / 周报 / 创建流程
```

| 为什么不是 5 个平级 tab | 说明 |
|---|---|
| 地图本身就是"首页" | 机构/设施不需要独立 tab——它们**就在地图上**，点设施即进入 |
| 机构不占 tab | 机构 = 地图上的建筑，给它一个列表反而是退化 |
| 星港养成并入地图 | 公共设施也在地图上（或从地图的"星港"浮标进入），不再单开页 |
| 星图独立 | 深空层是**另一种空间**（球外），与星球地图并列最合理 |

**结果**：底栏 4 项（今日 / 星图 / 复盘 / 我的）+ 中央主按钮。比原方案的 5 tab 更少、更聚焦。

## 三、关键布局规范

### 3.1 网格与安全区

| 项 | 值 |
|---|---|
| 基准屏 | **390 × 844**（iPhone 逻辑分辨率），另出一版 360×800 适配校验 |
| 左右安全边距 | **16**（内容宽 358） |
| 顶安全区 | 状态栏 47 + 8 = 55 起 |
| 底安全区 | Home 指示条 34 |
| 圆角 | 卡片 16 / 面板 20 / 按钮 12 / 芯片 pill |
| 8pt 栅格 | 所有间距为 4 的倍数（主用 8/12/16/24/32） |
| 触控最小 | 44 × 44 pt |

### 3.2 优先级顺序（竖屏从下到上）

```
Home 指示条 (34)
  ↑
中央主按钮（56 圆形，吸底上缘 +34）
  ↑
底栏（56）
  ↑
舱窗面板（默认 2/3 高，可拖 40%–85%）
  ↑
HUD 顶栏（55 + 48）
```

### 3.3 双形态切换（同屏过渡）

| 步骤 | 时长 | 说明 |
|---|---|---|
| 1 | 0–120ms | 星球左移出 + 缩放到"列表头图"尺寸（0.35×） |
| 2 | 80–320ms | 列表从右滑入，首 3 行错峰淡入（stagger 40ms） |
| 3 | 320ms | 完成；底栏高亮切到「今日」 |
| 反向 | 同上，镜像 | 保留滚动位置与筛选 |

**状态保留**：切换不重置滚动位置、不重置选中机构筛选、不重新请求数据。

## 四、视觉方向

### 4.1 两套视觉语言（分工明确，不混用）

| | **三维主界面（星球/星图/HUD）** | **列表与表单（今日/设置/复盘）** |
|---|---|---|
| 质感 | 有光照、有材质、有大气 | 扁平、高可读、无装饰 |
| 颜色 | 随相位变化的动态色（见 4.2） | 固定中性色阶（见 4.3） |
| 文字 | **只存在于 HUD，永不投射到球面** | 正常文本层 |
| 动效 | 丰富（转动、光照、脉冲） | 克制（≤200ms 过渡） |

**铁律**：三维场景与列表之间用**同一套色板锚点**（同一时间点的主色一致），否则两形态会像两个 App。

### 4.2 三维场景色板（相位驱动）

| 相位 | 星球主色 | 高光 | 天空/星空 | HUD 主题 | 强调色 |
|---|---|---|---|---|---|
| 晨 dawn | `#2A3550` | `#C98A5A` | `#151C2E` | 暗底 | `#E8A468` |
| 昼 day | `#4A6FA5` | `#F2E4C9` | `#7FA3C9` | **亮底** | `#2C6BB0` |
| 昏 dusk | `#3A2F44` | `#D96A4A` | `#1A1424` | 暗底 | `#E06A48` |
| 夜 night | `#101A2C` | `#3A5A80` | `#060A12` | 暗底 | `#5A9BD4` |
| 深夜 deep | `#0A1020` | `#24344E` | `#03050A` | 暗底 | `#4A7FB0` |
| 极昼/极夜 polar | 特殊 | — | 特殊 | 随亮度 | — |

**强调色使用配额**：强调色（琥珀/橙）在三维界面占屏面积 **≤8%**，只用于：信号灯、聚焦浮标、主按钮、相位徽标。理由：**夜里光本来就少**，铺开就没重点了。

### 4.3 UI 中性色阶（列表与表单）

| 令牌 | 值 | 用途 |
|---|---|---|
| `bg/canvas` | `#0E1218`（暗）/ `#F5F6F8`（亮） | 页面底 |
| `bg/surface` | `#161B23` / `#FFFFFF` | 卡片 |
| `bg/elevated` | `#1D232C` / `#FFFFFF` + 阴影 | 面板 |
| `line/subtle` | `#232A35` / `#E6E8EC` | 分隔线 |
| `line/edge` | `#2E3745` / `#C9CDD4` | 控件描边 |
| `text/primary` | `#E9EDF3` / `#12161C` | 一级 |
| `text/secondary` | `#9BA6B4` / `#5A6069` | 二级 |
| `text/tertiary` | `#5E6A78` / `#8B9096` | 三级/占位 |
| `accent/amber` | `#E8A468` | 待办信号 |
| `accent/green` | `#5FBF8F` | 已完成信号 |
| `state/warn` | `#D9A03C` | 警告 |
| `state/danger` | `#C4614E` | 破坏性操作（归档/删除） |

**对比度**：所有文字对背景 ≥ 4.5:1；三级文字用于非关键信息，≥ 3:1。

### 4.4 字体

| 用途 | 字体 | 字号 | 字重 |
|---|---|---|---|
| HUD 主数字（等级/时间） | 等宽数字字体（如 MiSans Mono / SF Mono） | 15–17 | 500 |
| 标题 | 系统中文字体（MiSans / PingFang） | 20–28 | 600 |
| 正文 | 同上 | 15 | 400 |
| 说明/标签 | 同上 | 13 | 400 |
| 极小注（来源/日期） | 同上 | 11 | 400 |
| 知识卡大号数字 | 等宽数字 | 32–40 | 600 |

**不引入花哨字体**：中文像素风字体在小字号下的可读性风险高（需要在 12px 网格下逐字校验）。像素风只在"设施铭牌"这一处作为**装饰层**出现（≤10 字、固定 12px 网格校验），不作为 UI 正文字体。

## 六、动效预算

| 场景 | 时长 | 曲线 | 预算说明 |
|---|---|---|---|
| 星球自转（空闲） | 连续 | linear | 0.6°/s，30fps 即可 |
| 设施脉冲（入轨） | 600ms | ease-out | 一次 |
| 晨昏推进（结算） | 1200ms | ease-in-out | 每天最多 1 次的相位过渡 |
| 锚点点击反馈 | 160ms | ease-out | 缩放 1.0→1.06→1.0 |
| 舱窗面板展开 | 240ms | ease-out | 位移 + 透明 |
| 双形态切换 | 320ms | ease-in-out | 见 3.3 |
| 结算抽屉 | 280ms | ease-out | — |
| T1 微光 | 400ms | linear | 星点闪 |
| T4 彗星 | 2400ms | ease-out | 掠过轨迹 |
| 列表过渡 | ≤200ms | ease-out | 克制 |

**约束**：任何非用户触发的动效，单次 ≤1.2s；页面加载后不得有 >1 个并行动效；`prefers-reduced-motion` 时全部降级为淡入淡出。

## 七、无障碍与降级

| 项 | 做法 |
|---|---|
| 纯列表模式 | 三维不可用/不想用时，今日列表升为主视图，一切功能可达 |
| 动态字体 | 支持系统字号放大到 130%；HUD 文字随之放大并重排 |
| 对比度 | 所有文字 ≥4.5:1（含 HUD 在亮相位下） |
| 色盲 | 状态不只用颜色：待办=闪烁、完成=常亮+勾、停机=灭灯（形状/动效区分） |
| 减弱动态 | `prefers-reduced-motion` → 关自转、关脉冲、关彗星 |
| 屏幕阅读器 | 三维场景提供等价文本："星球地图，5 个机构，今日完成 4 / 6。可用列表模式查看。" |
| 键盘/桌面 | 设施 Tab 遍历，Enter 打开，Esc 返回 |
