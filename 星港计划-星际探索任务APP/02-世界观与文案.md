# 02 · 世界观与文案
## 一、世界：一颗小星球上的星港
**一句话**：一颗小到你能看遍的星球；机构是它地面上的建筑，长在你真实花掉的时间里；抬头是深空，那些光是你学到的知识。

| # | 世界事实 | 对应的产品事实 |
|---|---|---|
| A | **推进值只能由燃烧真实时间产生**：不烧钱、不烧体力、不烧任务券，不可消费、不可购买、不可赠送 | 经验值不可消费；无商城、无消耗型货币 |
| B | **星球每天自转一圈**：晨昏线是真的，20:00 打开看到的就是此刻的明暗；明暗不记昨天、不针对谁 | 每日任务重置；光照随系统时间与当地日出日落；连续天数会断，历史不消失 |
| C | **星图只增不减**：营建过、点亮过的地块与勘测过、命名过的坐标永久留存，任何力量都擦不掉 | 永久记录不可回退；中断不删历史；停机设施不消失、不破败 |
| D | **信号里带着噪声**：深空通信永远混着无法解释的随机噪声，偶尔出现一段完整的东西；星港不生产惊喜，只是听见了 | 概率触发彩蛋；随机不改变难度、不改变判定 |
| E | **星球小到可以被看遍**：星港停泊在小星球地表，指挥官随时可从高空俯瞰全貌 | 三维球体视窗是主界面；机构 = 球面设施；恒星球在球外 |

## 二、五条世界法则
| 法则 | 世界观表述 | 界面上的硬性体现 |
|---|---|---|
| 一 | 燃料只能是真的 | 没有跳过／代打／自动完成；打开 App 不产生推进值 |
| 二 | 轨道不记仇 | 中断不计负分、不弹羞耻提醒、连续天数断了不降级、不扣推进值 |
| 三 | 入图者不还 | 任何机制（含扰动）不删除已入账数据；星图只增 |
| 四 | 航图在你手里 | 机构／计划／扰动全可关；休息日自由设定；随时可停可改可重置曲线 |
| 五 | 无人替你打分 | 无排行榜、无公开对比、无"超过 xx% 指挥官"、无社交 PK |
| 六 | 噪声不改航向 | 扰动永不影响任务成功判定与现实目标；概率表在设置页公开可查 |
## 三、角色与语气
**决策 AI**（全案约 80% 台词）：读数据、给判断、建议下一步；是坐在指挥席旁的副手，会判断、会拒绝、偶尔吐槽，但从不劝你努力。

| 层 | 人格 | 例 |
|---|---|---|
| ① 有判断 | 敢说"这个节奏不对"，给可执行建议 | 「连续 3 天 45 分钟都中止。降到 25 试试。」 |
| ② 有边界 | 不奉承、不安慰过度、不承诺结果 | 「记下了。」 |
| ③ 有立场 | 有偏好但服从用户，可被否决 | 「我建议改到早上。当然，你定。」 |
| ④ 有人味 | 短吐槽每日 ≤2 次，配额用完自动降级为 ①②③ | 「第 5 次。你确定不是打开就好？」 |

**语气规范**

| 规范 | 要求 |
|---|---|
| 三句原则 | 一次最多三句，能一句说完不写两句 |
| 先判断后建议 | 结论在前：「太长了。降到 25 分钟。」 |
| 只报状态、不劝只告知 | 「入轨。推进值 +40」／「可以只做一次。」 |
| 中断先承认事实 | 「轨道过去了。星港还在。」 |
| 不用叹号、用"你"不用"您" | 全案 0 个「！」；平视，不客套 |
| 不承诺结果 | 「8 周后你会有一段可回看的航迹。」 |
| 术语克制 | 一次对话最多 1 个自造词，其余用现实词 |
| 吐槽只吐槽情况 | ≤10 字，只吐槽情况不吐槽人 |

**三档人格**（设置项「副手语气」）：简洁（默认，只有 ①②③）／ 有人味（开启 ④，每日 ≤2 次）／ 纯报数（只剩状态与数字，无建议）。

**可用样本（≤8 句）**：星港在轨。舱内灯还没全开。／ 连续 3 天 45 分钟都中止。降到 25 试试。／ 入轨。推进值 +40 ／ 已过 07:00 窗。醒着的话就记一下。／ 这次没记上。之前 59 次都还在。／ 今天挑了个最难的。／ 天黑了。／ 记录留着。随时回来。

**观测台**（数字页 / 周报 / 知识卡署名）：只报数，不下判断。

| 场景 | 决策 AI 说 | 观测台说 |
|---|---|---|
| 完成 20 次 | 「第 20 次。这个机构稳了。」 | 「本周 20 次 · 累计 466 分钟。」 |
| 进步 | 「航迹在往上走。」 | 「4 周前每周 8 次 → 现在 18 次。」 |
| 中断回来 | 「轨道过去了。星港还在。」 | 「停机 6 天。历史 148 条，无删除。」 |

**远征**（阶段挑战）：不给台词、没有脸。中途停下写「本轮中断」，不写"你失败了"；已入账的一个不少。
## 四、叙事三层循环（无结局、无大反派；三层各有结算点，扰动挂在结算瞬间）
```
日循环（10–120 分钟，重复 7–30 次）：看航程 → 点火／过境 → 入轨 → 推进值 + 扰动
段循环（7 天–8 周，若干轮并行）：成立机构 → 立计划 → 逐日入轨 → 节点结算 → 研究成果
长线循环（月／季／年）：星港扩建 · 星图变密 · 知识集册 · 指挥官等级
```

## 九、关键屏文案（6 组，每组 ≤6 行）
- **序章**：星港在轨。舱内灯还没全开。／ 这里的燃料只有一种：你真实花掉的时间。／ 燃料只能是真的 ／ 轨道不记仇 ／ 入图者不还 ／ 先成立一个机构。今天就点第一次火。
- **主页面**：相位徽标「晨昏 · 06:12」；等级「Lv.12　推进值 4,180 / 4,800」；今日「今日 4 / 6」；主按钮「开始专注／进行中／暂停」；副手一句「连续 3 天 45 分钟都中止。降到 25 试试。」
- **结算**：标题「入轨」；归属「体能署 · 8周力量 · 第 5 格」；收益「推进值 +40　研究成果 +2」；扰动 T4「嚯。彗星。」；保底「再完成 7 次，必有极光或彗星。」
- **早起**：闹钟窗「07:00 窗」；解除「拖到刻度 ／ 或算一下 47 + 38」；确认「已过 07:00 窗。」；迟确认「已过 07:00 窗（迟）。」；未确认「这次没记上。之前 59 次都还在。」
- **周报**：「本周」；「9 次 · 227 分钟 · 达标 7 / 应做 9」；「4 周前每周 8 次 → 现在 18 次。」；「累计 148 次 · 无删除」；「这两周的节奏比之前松。」
- **错误**：「记录没同步上。本地这份还在。［重试］」／「没网也能计时。这份在你机器上。」／「已切省电渲染。」／「最近一次触发慢了 4 分钟。［检查电池设置］」
