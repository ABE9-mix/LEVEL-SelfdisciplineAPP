# 03 · 系统与流程（机构 → 计划 → 任务 → 执行）

> 本案的骨架是一条四层结构。设计目标是：**第一次配置 ≤60 秒，日常执行零配置，中断后可无损回来。**

---

## 〇、对象层级

```
指挥官 Commander
└── 机构 Agency（领域容器，1..N 个）
      ├── 徽记 / 代号 / 域色 / 编制
      └── 计划 Program（周期目标，1..N 个）
            ├── 周期 7d / 14d / 21d / 30d / 8w / 自定义
            ├── 频率（每周几次 / 每天）
            ├── 休息日
            ├── 节点 Node（阶段里程碑，即"远征"）
            └── 任务 Mission（可执行动作，1..N 个）
                  ├── 类型：定时 / 计数 / 布尔
                  ├── 执行方式：点火（番茄钟）/ 窗口（闹钟）/ 自由记录
                  └── 每次执行 → Session（航迹，永久）
                                    ↓
                        推进值 XP + 研究成果 RC + 扰动 roll
```

**为什么不把"机构"和"计划"合并**：机构是**身份**（我在这个领域有个部门），计划是**承诺**（我在某段时间内做某事）。一个机构会先后跑很多计划（8 周力量 → 12 周跑步），把它们分开，用户换计划时不会丢掉领域积累——这是降低"重新开始"成本的关键。

**为什么不把"任务"直接挂在今日**：任务属于计划，计划属于机构。这样"完成"才有归属（「体能署 · 8 周力量 · 第 5 天」），统计才有对照维度。

## 一、机构系统 Agency

### 1.1 预置模板（8 个，一键成立）

| 模板代号 | 建议名 | 覆盖领域 | 默认任务示例 | 主执行方式 | 成果系列 |
|---|---|---|---|---|---|
| `MED` | 体能署 | 健身、跑步、拉伸、体重 | 训练一次 / 晨跑 30 分钟 / 拉伸 10 分钟 | 点火 + 窗口 | 行星与卫星 |
| `KIT` | 膳食司 | 厨艺、控糖、饮水、记录饮食 | 做一道新菜 / 2L 饮水 / 不喝含糖饮料 | 自由记录 | 人类航天 |
| `LIT` | 文书记 | 阅读、写作、笔记、复盘 | 读 20 页 / 写 300 字 | 点火 | 深空天体 |
| `EDU` | 学研所 | 备考、专业课、刷题、错题 | 自习 45 分钟 / 错题 10 题 | 点火 | 恒星与星系 |
| `LIN` | 语言局 | 单词、听力、口语 | 听力 15 分钟 / 单词 20 个 | 点火 | 时间与坐标 |
| `WAK` | 晨昏站 | 早起、晨跑、晨间流程 | 07:00 起 / 起床后喝水 | **窗口（闹钟）** | 天空现象 |
| `MND` | 静观室 | 冥想、呼吸、情绪记录、睡前流程 | 冥想 10 分钟 / 23:30 放下手机 | 点火 + 窗口 | 天空现象 |
| `CRF` | 创构坊 | 乐器、绘画、摄影、编程 side project | 练琴 30 分钟 / 写代码 45 分钟 | 点火 | 深空天体 |
| `GEN` | 星学苑 | 天文、科普学习、观星 | 看一集科普 / 认一个星座 | 点火 | 全系列（稀有度加权） |

预置 9 个（含 `GEN`）。自定义机构不受数量限制。

### 1.2 成立流程（3 步，≤60 秒）

```
步骤 1  选模板 / 自定义            ← 默认停在"模板"页；自定义折叠在底部
步骤 2  起名 + 选域色 + 选徽记      ← 三项都有默认值，可整屏跳过
步骤 3  立第一个计划               ← 提供 3 条推荐计划（含周期与频率），选一条即可
完成    「挂牌。机构成立。」        ← 立刻在今日页出现 1 条今日任务
```

**字段清单**：

| 字段 | 必填 | 默认 | 上限 | 说明 |
|---|---|---|---|---|
| 名称 | ✅ | 模板名 | 12 字 | 自由命名（例："打铁部"、"深夜食堂"） |
| 代号 | ✕ | 模板代号 | 4 字符 | 大写拉丁，显示在徽记角标（例 `MED-07`） |
| 域色 | ✕ | 模板色 | 6 选 1 | 调色板内取色（保证对比度） |
| 徽记 | ✕ | 模板图 | 32×32 像素 8 选 1 | 可后续在设施里改 |
| 口号 | ✕ | 空 | 20 字 | 只出现在机构档案页，不影响任何数值 |
| 归档位 | ✕ | 自动 | — | 星图上机构锚点的坐标 |

**刻意没有的字段**：目标重量/目标体脂/课程总分等"结果指标"。理由：结果不由 App 判定，写进去只会制造"未完成"的负反馈。用户想写可以写在口号里。

### 1.3 机构状态机

| 状态 | 触发 | 界面表现 | 数据 |
|---|---|---|---|
| `draft` 筹备 | 成立但未跑过任何任务 | 虚线边框、灰徽记 | 不计入星图 |
| `active` 在轨 | 有进行中计划 | 亮徽记、域色描边 | 正常累计 |
| `idle` 巡航天 | 计划全部完成/暂停，30 天内无执行 | 半亮、标注"巡航" | 保留全部数据 |
| `parked` 停机 | 用户主动暂停 | 灰、保留入口 | 不再累计，**历史不动** |
| `archived` 归档 | 用户删除→归档 | 收进"档案舱"，可查看 | 永久只读，可一键恢复 |

**没有"机构衰败/解散"机制**。停机不扣任何东西，回来时"编制还在"。

### 1.4 编制 I0–I4（半养成的机构侧）

| 级 | 条件（两个都满足） | 解锁 |
|---|---|---|
| I0 | 成立 | 基础档案 |
| I1 | 累计 10 次执行 且 ≥3 个不同日期 | 徽记可改、口号槽 |
| I2 | 累计 30 次 且 完成 1 份计划 | 域色可改、子机构（拆分为 2 个） |
| I3 | 累计 100 次 且 覆盖 ≥2 类执行方式 | 机构专属成果册（可收藏）、档案页趋势图 |
| I4 | 累计 300 次 且 完成 ≥3 份计划 | 命名权（可为一个真实天体/设施部件命名）、旗舰徽记样式 |

**关键**：编制只解锁**表达与展示**，不解锁数值倍率。I4 的机构做番茄钟和 I0 的一样给 XP。（见 [04 §五 防刷与中立性](04-数值与成长经济.md)）

## 二、计划与任务

### 2.1 计划 Program 字段

| 字段 | 选项 | 默认 | 备注 |
|---|---|---|---|
| 名称 | 自由 | 模板推荐名 | ≤20 字，现实词优先 |
| 周期 | 7 / 14 / 21 / 30 天 / 8 周 / 自定义（3–365） | 14 天 | 第一版推荐 14 天（回报周期与新鲜感折中） |
| 频率 | 每天 / 每周 N 次 / 隔天 / 自定义周几 | 每天 | 允许"每周 3 次"这种非连续（消除"漏一天=断"的焦虑） |
| 休息日 | 选周几，或"每周自动留 1 天" | 无 | **主动设置休息日不计为中断**（写进周报） |
| 提醒 | 时间 + 方式（通知/无） | 20:00 | 每条任务可单独覆盖 |
| 目标量 | 每次时长（分钟）或次数（如 20 个）或布尔 | 25 分钟 | 允许留空（"今天做了就行"） |
| 难度档 | 轻量 / 标准 / 深空 | 标准 | 只影响 XP 上限与卡池稀有度，不影响判定 |
| 远征节点 | 自动按周期切 2–4 个节点 | 开 | 节点 = 里程碑，不是关卡 |
| 中断规则 | 宽容（默认）/ 严格 | **宽容** | 严格档：漏一天当周该计划标记为"需补做"，但**依旧不扣历史** |

### 2.2 任务 Mission 字段

任务是"一个动作"，不是"一天"。一份计划可以有 1–6 条任务。

| 字段 | 说明 | 例 |
|---|---|---|
| 名称 | 动词开头 | 训练一次 / 听 15 分钟 / 做一道新菜 |
| 类型 | `timed` 定时 / `count` 计数 / `bool` 布尔 | timed |
| 目标量 | 分钟 / 个数 / — | 30 分钟 |
| 排期 | 周几 + 一天内时段 | 一二三四五六，随时 |
| 执行方式 | 点火 / 窗口 / 自由记录 | 点火 |
| 提醒 | 复用计划或单独设 | — |
| 最小完成线 | 达到 60% 即算成功（可关） | 18 分钟算完成 |

**"最小完成线"是本案的一条反脆弱设计**：状态差的日子做完 60% 也算入账，避免"今天没力气 → 干脆不做 → 连续断了 → 放弃整个计划"。周报里诚实标注"达标 / 及格线达标"。

### 2.3 三层推荐（降低配置负担的核心）

用户只创建"机构"时，系统自动给出 3 条推荐计划（按模板 + 用户填的领域），每条推荐计划自带 2–4 条任务与排期。

```
成立「体能署」→ 推荐：
  ① 21 天 · 每天动 30 分钟            [采用]
  ② 8 周 · 每周 3 次力量               [采用]
  ③ 14 天 · 每天拉伸 10 分钟            [采用]
  ④ 自己立一份 →
```

**数据判据**：如果 >50% 用户走到"自己立一份"，说明推荐质量不足；如果 <10% 用户采用任何推荐，说明模板不像他们自己的话——两个方向都要改。

## 三、执行层（航天任务怎么跑）

三种执行方式覆盖自律计划的真实形态。

### 3.1 点火 IGNITION · 番茄钟专注

| 项 | 规则 |
|---|---|
| 时长档 | 15 / 25 / 45 / 60 分钟 + 自定义（1–180） |
| 开始 | 一个按钮，无二级确认。开始即锁定计时 |
| 计时精度 | 用 `elapsed = now − start` 计算，不累加 tick（避免后台漂移） |
| 后台 | 前台服务/Activity 保活 + 通知栏常驻；切后台继续计时并显示剩余 |
| 息屏 | 允许息屏（不强制亮屏）；回前台用时间戳续算 |
| 中断 | 中止 → `aborted`，给 30% XP（无扰动、无卡），标注"未完成"；退出 App 不自动中止 |
| 完成判定 | `elapsed ≥ target`（或 ≥ 最小完成线） → `success` |
| 完成表现 | 入轨动画（≤600ms）→ 结算抽屉（XP + 可能一张卡 + 扰动） |
| 连续专注 | 支持"任务串"（25+25 连打），每段独立 Session；不叠加 XP 递减 |
| 不做 | 不锁其他 App、不做强制专注模式、不用"专注失败扣树/扣建筑"这类惩罚 |

**为什么给"中止也有 30%"**：完全不给会让"试了但没撑住"变成零，而零是最容易放弃的反馈。给 30% 但不给稀有物（不抽卡、不 roll 扰动），既承认了付出的时间，也不奖励失败。

### 3.2 发射窗口 WINDOW · 早起闹钟

这是本案最需要诚实对待的部分：**闹钟响了人不一定真的起了**。

| 项 | 规则 |
|---|---|
| 设定 | 时刻 + 重复（工作日/周末/自定义周几）+ 贪睡次数（0–2） |
| 触发 | 系统精确闹钟 + 全屏来电式界面（需真实交互解除：拖到刻度 / 解一道 2 位数加法，二选一） |
| 记录窗 | 解除后 **30 分钟内**必须确认"我起床了"（一个按钮）→ `window_confirmed` |
| 迟确认 | 30–120 分钟 → `window_late`，仍计为成功，XP 减半 |
| 过期 | 未确认 → `window_missed`，**只标"未确认"**，不倒扣任何历史、不发愧疚通知 |
| 窗口分级 | 民用 / 航海 / 天文晨（−6°/−12°/−18°，按用户经纬度算真太阳时）——真早起有真天文可看 |
| 承接 | 确认后直接跳到该机构"今日第一条任务"，避免"起了然后呢" |
| 周末自动 | 休息日自动跳窗，并写明「今天没有窗。」 |

**晨昏蒙影的用法**：如果用户在"天文晨"之前解除闹钟，星图上点亮一枚**晨星**（真实成就，因为这是可核查的时刻）。这是本案少见的"真实世界给的奖励"，比虚拟币更有说服力。

**技术兜底（Android 杀后台）**：
1. `AlarmManager.setExactAndAllowWhileIdle` + `SCHEDULE_EXACT_ALARM` 权限引导；
2. 镜像一份**系统日历事件**（带提醒）作为第二链路；
3. 自研"窗口自检页"：显示最近一次触发时间、与设定时间的偏差，连续 2 次偏差 >2 分钟即提示电池白名单；
4. iOS 用 `UNCalendarNotificationTrigger` + Live Activity（可选）。

### 3.3 自由记录 LOG · 无计时打卡

| 项 | 规则 |
|---|---|
| 适用 | 护肤、饮水、记账、服药、"今天做了"这种不需要时长的动作 |
| 交互 | 今日页一行一个勾，两次点击内完成（列表勾 → 无弹层）；支持小组件/快捷指令 |
| 反馈 | 轻量 toast（无动画、无结算抽屉）——**不要为一次喝水放一段 600ms 动画** |
| XP | 固定低值（见 04）；不参与稀有扰动 roll（避免"为了抽卡去点勾"） |

### 3.4 执行方式选择建议（写在模板里，用户可改）

| 现实动作 | 推荐方式 | 为什么 |
|---|---|---|
| 自习、刷题、写作、练琴 | 点火 | 时长即质量 |
| 健身（力量） | 点火（可自由记录） | 有时长按住节奏 |
| 跑步 | 点火 或 外部运动数据 | 与运动 App 打通留 P5 |
| 早起 | 窗口 | 只有闹钟能判定 |
| 护肤、饮水、服药 | 自由记录 | 无需时长 |
| 阅读 | 点火 或 计数（页数） | 因人而异，给两个选项 |
| 冥想 | 点火（15 分钟档） | 时长有效 |

## 四、结算与入账

一次成功执行 → 结算抽屉，**四层信息，顺序固定**（先给确定性，再给随机性）：

```
┌ 结算 ──────────────────────────┐
│ 入轨                            │  ① 判定：成功/及格线/中止
│ 体能署 · 8周力量 · 第5格         │  ② 归属：让完成有名字
│ 推进值 +40                      │  ③ 确定收益（必给，不打折）
│ ─────────────────────           │
│ [扰动 0.6s roll 动画]           │  ④ 随机层（见 06）
│ 研究成果入库 · G2               │
│ 「地球的一天其实不是 24 小时」   │
│ [看全文]  [收下]                │
└────────────────────────────────┘
```

**规则**：

| 规则 | 内容 |
|---|---|
| 必给优先 | 推进值一定显示，扰动一定在后面；不能出现"完成但什么也没给"的空白结算 |
| 知识卡节流 | 同一 Session 最多 1 张卡；同一天最多 3 张；未读的卡进"待归档"，不堆积超过 5 张 |
| 递减可见 | 当日第 4 次起，推进值显示为 `+12（今日递减）`，**明说**，不做隐藏衰减 |
| 无强制互动 | 不要求"看完知识才能继续"；`[收下]` 永远一秒可达 |
| 可静音 | 设置里"关掉随机扰动"→ 结算只剩 ①②③，界面不留灰位 |

## 五、中断、暂停、恢复（全案最需要克制的地方）

### 5.1 三段式

```
① 漏（自动发生，不弹窗、不发推送指责）
   决策 AI  这次没记上。
   观测台   之前 59 次都还在。
   数据     XP 不回退、星图不减少、等级不降级、地图上设施不破败

② 补（用户主动，可以永远不做）
   决策 AI  今天可以补一次。
   交互     「补做」按钮出现在停机 ≤7 天的计划卡（设施面板 L2）上
   效果     恢复"当期连续性"，夺回当周节点进度的 50%（不是 XP，XP 不追溯）

③ 回来（隔了很久）
   首屏    「轨道过去了。星港还在。」
   数据页  「停机 22 天 · 历史 148 条 · 无删除」
   动作    只给一个入口：[排今天的事]
```

### 5.2 三条禁止

| 禁止 | 原因 |
|---|---|
| ❌ 不写"你已连续中断 N 天" | 把中断变成负债（改为"停机 N 天 · 历史无删除"） |
| ❌ 不发"好久不见！我们想你了"推送 | 思念式推送是羞耻感的包装 |
| ❌ 不做等级/建筑回落 | 违反法则三；一次回落足以让用户删除 App |

### 5.3 允许的事

| 允许 | 说明 |
|---|---|
| 主动留白 | 用户设置休息日 → 该日不计为漏（周报单列"计划休整"） |
| 中途改频率 | 每周 5 次改成 3 次，历史不重算；改动作当期生效 |
| 分段重启 | 同一份计划可"重新起算一个周期"（保留上一段完整记录，作为"上一次远征"归档） |
| 曲线重置 | 周报里提供"我不看连续天数"开关（连续数隐藏，只留总量与趋势） |

## 六、核心用户流程（6 条）

> **主界面形态：三维星球地图为主 + 今日列表一键切**（见 [10-星球地图与三维场景](10-星球地图与三维场景.md)）。下文流程按新形态书写。

### F1 首次到第一次成功（≤5 分钟，激活关键）

```
启动 → 序章 4 屏（第 1 屏即为真实三维星球场景）
→ [成立机构] → 拖动"选址光标"在球面落位（可跳过，系统取空位）
→ 选模板「体能署」→ 起名(默认) → 选一条推荐计划
→ 设施出现在球面，亮起"营建"状态；今日列表出现 1 条任务
→ [开始专注] → 25 分钟（演示可 90 秒）
→ 入轨动画 → 设施脉冲 + 信号灯转绿 → 结算：XP + 第一张知识卡(T0 必出)
→ 星图亮起第一颗
```
判据：完成率 ≥70%、耗时中位数 ≤4 分钟。若流失集中在"起名/选色/选址"步骤 → 把三项合并为一屏并可整屏跳过。

### F2 每日主循环（老用户）

```
打开 → 星球地图（顶栏：相位 + 等级；决策 AI 一句话）
→ 看哪座设施在闪（待办=琥珀慢闪）
→ 点设施 → 舱窗面板弹出（地图保持可见）→ [开始专注]
→ 完成 → 设施亮一格、信号灯转绿 → 关闭面板
→ 全部完成 → 决策 AI 一句话：「今天的航程走完了。」（不加任何催促做更多）
```
**快捷路径**：不想转星球/不想点设施的老用户，按底栏「今日」切列表形态 → 直接勾选。两形态共享数据与筛选状态，切换 ≤320ms。

### F3 早起闭环

```
07:00 全屏窗 → 拖刻度解除 → 「已过 07:00 窗」
→ 直接跳到当日第一条任务（不要求先打开地图）
→ 07:20 前完成点火 → 结算 + 「晨星」标记（若在天文晨 −18° 之前）
→ 回到地图时，星球光照已推进到 dawn → dusk 相位（真实的，不是动画）
```

### F4 计划节点结算（远征完成）

```
最后一个 Session 成功 → 节点结算页（长版，唯一允许长文案的屏）
→ 显示：周期内 次数/分钟/达标率/漏了几格/休息日
→ 发放：成果卡（节点保底 1 张，难度越高稀有度上限越高）+ 徽记 + 称号
→ 地图联动：该设施完成一次"加建"（脚手架拆除动画）→ 地块点亮一格 → 星图新增一段航迹
→ 下一段邀请（可拒绝，拒绝无副作用）
```

### F5 长期无进展（连续 2 周未达标）

```
周报页出现「这两周的节奏比之前松。」（观测台，只陈述）
→ 决策 AI 给出 3 个可一键采纳的动作：
   [把频率降一档] [换一份计划] [什么都不改，继续]
→ 绝不出现"再坚持一下哦"
```

### F6 删除 / 归档（必须顺滑）

```
点设施 → 面板 L2' → 归档 → 「记录留着。随时回来。」
→ 设施做一次落光动画，**保留低亮度轮廓在球面上不动**（可一键恢复）
不做挽留弹层、不做"你确定要失去所有进度吗"式恐吓。
```

## 七、主界面信息优先级（星球地图 + 今日列表）

### 7.1 地图形态（默认）

| 优先级 | 内容 | 为什么在这 |
|---|---|---|
| 1 | 星球本体 + 设施信号灯 | 用户一睁眼要看到"哪里有事在等我"（琥珀慢闪） |
| 2 | HUD 底栏「今日」`4/6` 胶囊 | 今天还剩几件，一眼可读 |
| 3 | 中央「开始专注」主按钮 | 最短路径：一到两次点击进执行 |
| 4 | 顶栏相位 + 等级细条 | 真实时间与长期积累（低频扫视） |
| 5 | 决策 AI 一句话 | 有建议才出现，8 秒淡出，不占位 |

### 7.2 列表形态（副视图）

| 优先级 | 内容 |
|---|---|
| 1 | 今日待办任务列表（按机构分组，含窗口标记） |
| 2 | 今日进度（N/M + 一根细条） |
| 3 | 进行中的计划（最多 3 条） |
| 4 | 星港状态一行摘要（等级 / 在轨设施数） |
| 5 | 今日扰动摘要（有则显示，无则不占位） |

**两形态都刻意不放**：排行榜、活动 banner、推送位、签到、任务商城、每日新闻。

**最短路径要求**：
- 冷启动 → 开始第一条专注：**地图形态 ≤ 3 次操作**（点设施 → 面板内 [开始专注]），**列表形态 ≤ 2 次**（任务卡 → 开始）；
- 任何新增功能不得把这条路径变长。

## 八、系统边界一览

| 系统 | 有 | 没有 |
|---|---|---|
| 三维地图 | 球体、相机固定位姿、真实昼夜光照、设施锚点、HUD、舱窗面板 | 自由飞行、地形起伏、实时阴影、文字进场景、多角色 |

| 计划 | 周期、频率、休息日、节点、难度档、宽容/严格 | 甘特图、依赖关系、里程碑排程、项目 |
| 任务 | 三种类型、三种执行方式、最小完成线 | 子任务树、标签系统（v1 只做机构归属）、优先级 |
| 执行 | 计时、闹钟、记录、后台保活 | 白噪音（P5）、网站屏蔽、强制专注 |
| 奖励 | XP、RC、知识卡、扰动、徽记、命名权 | 货币、商城、消耗、抽卡付费 |

| 决策 AI | 状态播报、可执行建议（可一键采纳/拒绝）、三档人格 | 替用户做决定、自动改计划、催促推送 |
| 数据 | 星图、周报、趋势、导出 | 云账号（v1）、社交、分享榜单 |
