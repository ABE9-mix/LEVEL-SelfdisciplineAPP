# 02 · 世界观与叙事

> 叙事在本产品里**只承担三件事**：解释规则的合理性、降低中断的羞耻、给抽象数值一个可想象的形象。
> 不承担：讲故事、给结局、给情绪糖。

---

## 一、世界：一颗小星球上的星港

### 一句话

**一颗小到你能看遍的星球。你的机构是它地面上的建筑，长在你真正花掉的时间里；抬头是深空，那些光是你学到的知识。**

### 五条世界事实（世界观只需要这五条）

| # | 世界事实 | 内容 | 对应的产品事实 |
|---|---|---|---|
| **A** | **推进值只能由燃烧真实时间产生** | 星港不烧钱、不烧体力、不烧任务券。它只烧一种燃料：**指挥官亲自度过的时间**。所以推进值不能被消费、不能被购买、不能被赠送，只能让它变多。 | 经验值不可消费；无商城；无消耗型货币 |
| **B** | **星球每天自转一圈** | 星港所在的星球随真实时间转动，昼夜分界（晨昏线）是真的：**你在 20:00 打开，看到的就是此刻真实的晨昏线**。明暗是这颗星球的 mechanics，不是奖赏也不是审判——它不记得昨天，也不针对谁。 | 每日任务重置；光照随系统时间与当地日出日落；连续天数会断，但历史永不消失 |
| **C** | **星图只增不减** | 星球上被营建过、被点亮过的地块，以及深空里被勘测过、被命名过的坐标，永久留在那里。**没有任何力量能擦掉它——包括指挥官自己的失误。** | 永久记录不可回退；中断不删除历史；停机设施在地图上不会消失或破败 |
| **D** | **信号里带着噪声** | 深空通信永远混着无法解释的随机噪声。偶尔，噪声里会出现一段完整的东西。**星港不生产惊喜，它只是听见了。** | 概率触发彩蛋；随机不改变难度、不改变判定 |
| **E** | **星球小到可以被看遍** | 星港不在地球轨道上，而是停泊在一颗小星球的地表——它小到指挥官能随时从高空俯瞰全貌。**看得见全貌，才谈得上"这是我的"。** | 三维球体地图是主界面；机构 = 球面设施；恒星球在球外 |

> **B、C、E 是全案的地基**：B 让"重新开始"成为自然现象（不是失败），也让早起有了真实的对照物；C 让"积累"成为可信赖的承诺（不是随时被没收的诱饵）；E 让积累**看得见**——空间比数字更能证明你没有白过。
> D 让随机量在世界观里合法——**它不是抽奖机，是宇宙本来的样子**。

### 1.1 空间结构：内圈是积累，外圈是知识

```
        ┌── 深空（星图 / 知识卡 / 命名权 / 观测台解锁的天体）──┐
        │                                                      │
        │              ┌──────────────────────┐                │
        │              │  小星球「晨昏」       │                │
        │              │  ─ 球面：你的机构     │                │
        │              │     （建筑 = 领域）    │                │
        │              │  ─ 地面：被点亮的地块  │                │
        │              │  ─ 晨昏线：真实时间    │                │
        │              └──────────────────────┘                │
        │                                                      │
        └──────────────────────────────────────────────────────┘
   探索的终点在球外（你学到了什么），基地的积累在球上（你做到了什么）。
```

**探索不等于占领**：星港不"征服"星球，也不"占领"深空。它只做两件事——**在自己的星球上营建**，和**抬头记录**。这是本作的太空观，也是写作红线的来源（见 §八）。

*详细的三维规格（相机、球体、光照相位、设施形制、HUD、舱窗面板、性能预算）见 [10-星球地图与三维场景](10-星球地图与三维场景.md)。*

## 二、五条世界法则（= 五条设计原则的世界化表达）

| 法则 | 世界观表述 | 对应设计原则 | 界面上的硬性体现 |
|---|---|---|---|
| 一 | **燃料只能是真的** | 行动先于表达 | 没有任何"跳过／代打／自动完成"；不能靠打开 App 就获得推进值 |
| 二 | **轨道不记仇** | 失败后可以重新开始 | 中断不计负分、不弹羞耻提醒、连续天数断了不降级、不扣推进值 |
| 三 | **入图者不还** | 永久记录不可回退 | 任何机制（含扰动）都不删除已入账数据；星图只增 |
| 四 | **航图在你手里** | 结构与难度自主选择 | 机构／计划／扰动全部可关；休息日自由设定；随时可停可改可重置曲线 |
| 五 | **无人替你打分** | 只对自己负责 | 无排行榜、无公开对比、无"超过 xx% 指挥官"、无社交 PK |

**新增第六条（本案特有）**：

| 六 | **噪声不改航向** | 随机不改变难度 | 扰动永不影响任务成功判定、永不改变现实目标；概率表在设置页公开可查 |

## 三、角色与语气规范

只设三个"说话的东西"，第四个刻意不给台词。

### 3.1 指挥官（用户）

不设姓名、性别、外貌、履历、出身行星。**空缺是刻意的**——用户才能把自己放进去。所有文案称 **"你"**，界面里的身份词是 **"指挥官"**。

可自定义（在"我的"里）：指挥官代号、座舱呼号、旗徽。这三项是**唯一被鼓励的身份投射**。

### 3.2 决策 AI DECISION AI（引导语气 · 全案 80% 台词）

星港的调度智能。它**管三件事**：读你的数据、给判断、建议下一步。它不是导师、不是教练、不是宠物、不是秘书——是**一个坐在指挥席旁边的副手，会判断、会拒绝、偶尔会吐槽，但从不劝你努力**。

**它的四层人格（按重要度排序）**：

| 层 | 说明 | 例 |
|---|---|---|
| ① 有判断 | 敢说"这个节奏不对"，并给出可执行建议 | 「连续 3 天 45 分钟都中止。降到 25 试试。」 |
| ② 有边界 | 不奉承、不安慰过度、不承诺结果 | 「记下了。」而不是「你太棒了」 |
| ③ 有立场 | 有偏好但服从用户，允许被否决 | 「我建议改到早上。当然，你定。」 |
| ④ 有人味 | 偶尔一句短吐槽，**全案每天不超过 2 次** | 「第 5 次。你确定不是打开就好？」 |

**第 ④ 层是配额制**：短吐槽由"当日配额"控制，避免变成话痨。超出配额时自动降级为①②③层。

**语气规范**：

| 规范 | 要求 | 例 |
|---|---|---|
| 三句原则 | 一次最多三句；能一句说完不许写两句 | — |
| 先判断，后建议 | 结论在前，建议在后 | ✅「太长了。降到 25 分钟。」　❌「要不要考虑调整一下时长呢？」 |
| 只报状态，不做情绪评价 | ✅「入轨。推进值 +40」　❌「你太棒了！」 | — |
| 不劝，只告知 | ✅「可以只做一次。」　❌「你应该坚持下去。」 | — |
| 中断后先承认事实 | ✅「轨道过去了。星港还在。」　❌「没关系，重新开始就好！」 | — |
| 不用叹号 | 全案 0 个「！」 | — |
| 用"你"，不用"您" | 平视，不客套 | — |
| 不承诺结果 | ✅「8 周后你会有一段可回看的航迹。」　❌「8 周脱胎换骨」 | — |
| 不安慰过度 | 用户回来时不给情绪糖，给下一步动作 | 「下一步：点火一次。」 |
| 术语克制 | 一次对话里最多 1 个自造词（如"入轨"），其余用现实词（番茄钟、闹钟、提醒） | — |
| 吐槽必须短 | ≤10 字，且**只吐槽情况，不吐槽人** | ✅「今天挑了个最难的。」　❌「你也太懒了」 |
| 可被关掉 | 设置里可把人格降到"纯报数" | 见下 |

**人格档位（设置项「副手语气」）**：

| 档 | 行为 | 适合 |
|---|---|---|
| 简洁（默认） | 只有①②③层 | 大多数人 |
| 有人味 | 开启④层短吐槽（每日 ≤2 次） | 喜欢角色感的用户 |
| 纯报数 | 只剩状态与数字，无建议 | 只要工具的用户 / 无障碍场景 |

**可直接用的语气样本**：

```
首次启动      星港在轨。舱内灯还没全开。
              这里的燃料只有一种：你真实花掉的时间。
机构空状态    还没有机构。星球是空的。
计划空状态    这个机构还没有任务。
当日空状态    今天还没有排进任务。
点火完成      入轨。推进值 +40
              今天第 3 次。
窗口过境      已过 07:00 窗。醒着的话就记一下。
未确认        这次没记上。之前 59 次都还在。
取得成果      研究成果入库。
              地球的一天其实不是 24 小时。
扰动 T3       舱外有光。今天多给 20%。
稀有 T4       嚯。彗星。
周报          本周 9 次，共 227 分钟。上周 5 次，132 分钟。
天黑了        天黑了。（每天仅一次，随真实晨昏线切换）
判断样本      连续 3 天 45 分钟都中止。降到 25 试试。
吐槽样本      今天挑了个最难的。            ← 每日配额 ≤2
停掉机构      记录留着。随时回来。
离线/错误     没网也能计时。这份在你机器上。
```

**"决策"体现在哪（不是只会说话）**：它必须能读到下列数据并给出**具体、可执行、可一键采纳**的建议，否则"决策 AI"这个名字就是虚的。

| 输入信号 | 判断 | 建议（可一键采纳） |
|---|---|---|
| 某档时长连续 2–3 次中止 | 目标量偏高 | 「45 → 25 分钟」[采纳] |
| 一周内某任务 0 次完成 | 排期不合理 | 「从每天改到每周 3 次」[采纳] |
| 窗口过境连续 3 次迟确认 | 闹钟时间偏早 | 「07:00 → 07:20」[采纳] |
| 同一机构 14 天无执行 | 承诺过重 | 「先停机，或缩到 1 条任务」[选择] |
| 完成集中在深夜 | 节律风险 | 「这个机构的推荐时段是 22:00 后」 |
| 某一机构完成率显著高于其他 | 优势领域 | 「文书记是你最稳的一个。」（只陈述，不排名） |
| 用户新建机构时 | 领域识别 | 自动推荐 3 条计划（见 03 §2.3） |

**所有建议必须是"可拒绝的"**：采纳率是观测指标，但不是设计目标——强迫采纳的建议等于替用户做决定，违反法则四。

### 3.3 观测台（数据与陈述语气 · 成长页 / 复盘页 / 知识卡署名）

负责所有数字页面。**只报数，不下判断**——数字本身已经足够，加一句评价会让用户觉得被审视。

| 场景 | 决策 AI 说 | 观测台说 |
|---|---|---|
| 完成 20 次 | 「第 20 次。这个机构稳了。」 | 「本周 20 次 · 累计 466 分钟。」 |
| 进步 | 「航迹在往上走。」 | 「4 周前每周 8 次 → 现在 18 次。」 |
| 退步 | 「这两周松了。要降一档吗？」 | 「本周 12 次，上周 18 次。」 |
| 中断回来 | 「轨道过去了。星港还在。」 | 「停机 6 天。历史 148 条，无删除。」 |

观测台是**知识卡的署名者**：每张卡右下角标 `观测台 · 收录`，让"教育"这一层由一台机器负责，而不是由一个劝你的人负责。这大幅降低了说教感。

### 3.4 长航时远征（阶段挑战 · 不给它台词）

**关键设计决策：远征不说话、没有脸、没有名字以外的性格。**

一旦它被拟人（有台词、有表情、有敌意），用户就会期待"打赢它"，产品就滑向战斗叙事——而战斗叙事在自律产品里是错的：**战斗可以不打，习惯不能不做**。

所以：

- 界面上保留通用词 **阶段挑战 / 计划节点**，世界里的名字是 **远征**（例：`八周远征 · 力量`）；
- 远征只有**属性**：持续多久、最难的一格在哪、走完会刻什么印；
- 中途停下时不写"你失败了 / 被击败"，写 **「本轮中断」**；已入账的东西一个不少。

## 四、叙事弧：三层嵌套循环（不是一条线）

自律产品的剧情**不能有结局**——通关之后就没动力了。所以不写三幕式故事线，写三个嵌套循环：

```
┌─ 日循环（每天，10–120 分钟）──────────────────────┐
│  看航程 → 点火/过境 → 入轨 → 推进值 + 扰动        │  ← 今日页 / 计时页
└────────────────────────────────────────────────┘
        ↑ 重复 7–30 次
┌─ 段循环（一份计划：7 天–8 周）─────────────────────┐
│  成立机构 → 立计划 → 逐日入轨 → 节点结算 → 研究成果│  ← 机构 / 计划 / 结算页
└────────────────────────────────────────────────┘
        ↑ 若干轮并行
┌─ 长线循环（月 / 季 / 年）─────────────────────────┐
│  星港扩建 · 星图变密 · 知识集册 · 指挥官等级       │  ← 星港 / 星图 / 复盘
└────────────────────────────────────────────────┘
```

**为什么这套循环扛得住"每天重复"**：

| 手法 | 效果 |
|---|---|
| 轨道每天过晨昏线 | 每天都有"事"在发生，不需要编剧供新剧情 |
| 星图只增不减 | 进度永远可见、永不清零 |
| 没有大反派、没有结局 | 不会"通关即失去意义" |
| 三层循环各自有结算点 | 完成 1 天 / 1 计划 / 1 季 都各有一次"入账感" |
| 扰动挂在结算瞬间 | 重复本身被注入了可变奖励 |
| 知识有真实稀缺性 | 稀有卡不是靠"更多"，是靠"更难拿到"，天然限制疲劳 |

## 五、序章（首次启动 · 4 屏，一辈子只播一次）

| 屏 | 画面 | 文本（≤3 行） | 交互 |
|---|---|---|---|
| 1 | 黑底，**一颗缓慢自转的小星球**由远及近，最后停在默认视角；地表一格一格亮起（**摄像机固定、球体自转**——第 10 章的核心手感在这里第一次建立） | 「星港在轨。舱内灯还没全开。」 | 点任意处 |
| 2 | 燃料槽：唯一一格，标签写着"真实时间" | 「这里的燃料只有一种：你真实花掉的时间。」 | — |
| 3 | 三条规矩（逐条入场） | 燃料只能是真的 ／ 轨道不记仇 ／ 入图者不还 | — |
| 4 | 星球上出现一个空的**选址光标**（可用手指拖动） | 「先成立一个机构。今天就点第一次火。」 | [成立机构] / 拖动选址 |

规则**一次说完、之后永不重播**。第二次出现就是说教。

**序章的落点就绪**：序章第 1 屏和第 4 屏**必须用真实的三维场景**（哪怕是最低档位），不能先播一段视频再进入三维界面——否则用户建立的手感是"看"而不是"转"，第一分钟就错了。若设备不支持三维（极老设备 / 省电模式），序章退化为静态星球贴图 + 平滑位移，交互文案改为"点任意处"。

第 5 屏（可选，A/B 位）：让用户体验一次 **90 秒的微型点火**，当场看到入轨动画 + 第一张知识卡（T0 级、必出）。
**理由**：在注册/配置之前先给一次"完成的感觉"，比任何引导文案都能说明这个 App 是干什么的。

### 序章的可降级版

对"我不想建机构，我只想开始专注"的用户，第 4 屏提供一行小字：**「先随便专注一次 →」**，直接进入计时页，事后在结算页再邀请成立机构。

## 六、每个界面欠叙事什么（落点映射）

> **主界面形态已调整为「三维星球地图为主 + 今日列表一键切」**（见 [10-星球地图与三维场景](10-星球地图与三维场景.md)）。本表按新形态列出。

| 屏 / 节点 | 叙事元素 | 语气归属 | 落点要点 |
|---|---|---|---|
| 启动引导 | 星港在轨 · 唯一燃料 | 决策 AI · 陈述 | 三规矩一次说完；序章用真三维场景 |
| **星球地图**（主界面） | 你的星球 | 决策 AI · 一句话（≤18 字） | HUD 只报状态；一句话 8 秒淡出，不做欢迎语 |
| 地图 · 顶栏左（相位徽标） | 真实天光 | 无台词 | 「晨昏 · 06:12」，跟随当地日出日落 |
| 地图 · 顶栏右（等级） | 积累 | 观测台 | `Lv.12` + 细条；不写"连续 N 天" |
| 地图 · 聚焦设施浮标 | 部门现状 | 观测台 | 「体能署 · 8周力量 · 第5/24格」 |
| 地图 · 晨昏线切换 | 天亮了/天黑了 | 决策 AI · 每日 1 次 | 「天黑了。」（不重复、不煽情） |
| 地图 · 设施点击 | 进入部门 | — | 舱窗面板，地图保持可见 |
| **今日列表**（副视图） | 排班表 | 中性 | 现实词优先（任务名 = 用户写的名字）；与地图共享筛选状态 |
| 今日 · 点火完成 | 入轨 | 决策 AI · 最短 | 「入轨。推进值 +40」 |
| 今日 · 当日第 N 次 | 计数 | 决策 AI | 「今天第 3 次。」（推进值递减但语气不鼓励不批评） |
| 今日 · 空状态 | 空舱 | 决策 AI | 「今天还没有排进任务。」＋[排一个] |
| **设施面板** L1 | 部门档案 | 观测台 | 编制/计划/历史，只报数 |
| 设施 · 成立（选址） | 挂牌落地 | 决策 AI · 告知 | 模板优先，字段默认折叠；可选址 |
| 设施 · 停机 | 停而不失 | 决策 AI | 「记录留着。随时回来。」 |
| 计划面板 L2 · 创建 | 立计划 | 中性 | 周期/频率/休息日/提醒，全部现实词 |
| 计划 · 节点（远征） | 远征属性 | 决策 AI · 告知 | 说清"最难的一格"与"走完刻什么印" |
| **执行** · 计时页 | 舱内视角 | 无台词 | 只有一根倒计时 + 环；无激励文案（避免打断专注）；星球降亮度至 25% |
| 执行 · 中断 | 中止 | 决策 AI · 中性 | 「中止了。这次不计入。」（不批评、不挽留） |
| **结算** | 研究成果入库 | 观测台 | 唯一允许出现"知识"长文的屏；设施脉冲 + 晨昏推进一圈 |
| 结算 · 扰动 | 噪声 | 决策 AI · 短促 | T1 无声；T3/T4 才有一句话 |
| **星图**（深空） | 只增不减 | 观测台 | 页脚固定一句：「图上的东西擦不掉。」；星空真实亮星可点开知识卡 |
| **复盘** | 周报 | 观测台 · 纯数字 | 禁止出现"你真棒/继续加油" |
| **我的** · 设置 | 现实词 | 中性 | 概率公开入口在「扰动」分组；副手语气档位在「决策 AI」分组 |
| 全局 · 离线/错误 | 先保证再修 | 决策 AI | 「没网也能计时。这份在你机器上。」 |
| 全局 · 低档渲染 | 降级但完整 | 决策 AI · 一次性 | 「已切省电渲染。」（不重复提示） |

**降级路径**（呼应"即使不做游戏化也必须完整成立"）：

| 元素 | 关闭"星港表现层"后 |
|---|---|
| 任务 / 番茄钟 / 闹钟 / 统计 | **完整保留**（这是工具本体） |
| 推进值 / 等级 | 保留数值，隐藏建筑隐喻 |
| 三维星球地图 | 退化为**静态球体贴图 + 列表主界面**；"今日列表"升为主视图 |
| 知识卡 | 变成可主动查阅的"资料库"，不再作为奖励派发 |
| 扰动 / 彩蛋 | **不存在**（页面上不出现这些词，也不留灰掉的入口） |
| 星港设施 / 涂装 | 不渲染，退化为一张纯进度环 |
| 决策 AI | 降到"纯报数"档；导航与功能一律不受影响 |

> 世界观不是贴纸，是这台机器的默认表达方式；关掉它，工具还能自己站着。

## 七、太空隐喻 ↔ 现实动作 对照表（写作与开发的唯一真相源）

| 世界词 | 现实对应 | 使用规则 |
|---|---|---|
| 星港 | 你的账号 / 中心 | 可命名 |
| 星球「晨昏」 | 星港所在的这颗小星球（主界面场景） | 可命名；默认名"晨昏"，因其开发锚点在晨昏线附近 |
| 指挥官 | 用户 | 界面第二人称只用"你" |
| 决策 AI | 引导与建议的语气人格 | 设置项「副手语气」可切三档；可关掉吐槽层 |
| 机构 | 领域（健身、厨艺、语言…） | 可命名、可换徽 |
| 设施 | 机构在星球地图上的建筑本体 | 与「机构」一一对应；I0–I4 换形制，不是另开一个系统 |
| 锚点 / 选址 | 机构在球面上的落位 | 全球约 91 个可用位（12° 间距） |
| 晨昏线 | 星球上真实的昼夜分界（随系统时间与当地日出日落计算） | **不是贴图翻转**；柔和带约 0.27°（美术别做宽） |
| 相位 | 光照六态：晨 / 昼 / 昏 / 夜 / 深夜 / 极昼夜 | 顶栏徽标显示；驱动 HUD 亮暗主题 |
| HUD | 浮在三维地图上的状态层 | **只提示不编辑**；文字永不投射到球面 |
| 舱窗面板 | 点击设施后弹出的编辑面板 | 地图保持可见；最多 3 层推入 |
| 计划 | 周期目标（8 周力量课表） | 用用户自己的名字 |
| 任务 | 可执行动作（训练一次、听 15 分钟） | 用用户自己的名字 |
| 点火 | 番茄钟专注开始 | 首屏按钮用「开始专注」，"点火"只在动效/文案里出现 |
| 入轨 | 一次专注成功 | 结算标题 |
| 发射窗口 | 早起闹钟 / 时间窗 | 设置页写「闹钟窗口」 |
| 窗口过境 | 时间到达 | 「已过 07:00 窗」 |
| 推进值 | 经验值 | 界面写 XP，说明文字写"推进值" |
| 研究成果 | 知识卡 | 「研究成果 · 恒星」 |
| 星图 | 永久记录集（深空层） | 可点开回看；星空真实亮星可点开知识卡 |
| 远征 | 阶段挑战 | 与「阶段挑战」并列显示 |
| 扰动 | 随机彩蛋 | 设置项「随机扰动」 |
| 停机 | 暂停机构 | 「停机不算删除」；地图上设施**不消失、不破败** |

**红线**：任何一个世界词，如果找不到对应的现实动作，就不允许出现在界面上（例：不给"能量""体力""任务券""星币"这些没有现实锚点的资源）。

## 八、写作红线（易犯错误对照）

| ❌ 不写 | ✅ 改写成 | 原因 |
|---|---|---|
| 征服星辰大海 | 把今天这一格走完 | 太空是**坐标**，不是**领土**；不做占领叙事 |
| 打败拖延 / 干掉懒惰 | 今天排了两件事 | 不设敌人（远征没有脸） |
| 你已连续中断 3 天 | 停机 3 天。历史 148 条，无删除。 | 不把中断变成负债 |
| 前功尽弃 / 全没了 | 之前的都在。 | 违反法则三 |
| 你太棒了 / 真厉害 | 入轨。推进值 +40 | 不做情绪评价 |
| 加油！坚持就是胜利 | （删掉，换成具体动作） | 空鼓励无信息量 |
| 超过 92% 的指挥官 | （无此功能） | 法则五 |
| 冲刺 / 暴击 / 满血 / 击杀 / 掉落 | 无对应现实动作的词一律不用 | 游戏化空转 |
| 宇宙很大，你很渺小 | （不用） | 不制造无力的宏大感 |
| 必须 / 一定要 / 不许 | 可以 / 建议 / 如果愿意 | 保留自主选择 |
| 打卡成功，获得 500 星币！ | 记下了。 | 不虚构可消费货币 |
| 限时 3 天，错过不再有 | 「今天 07:00 有个窗口」 | 不做 FOMO |

**禁词表（脚本强制，见 `09-术语表与文案规范.md`）**：征服、占领、打败、战胜、消灭、击杀、拖延症、前功尽弃、荒废、加油、太棒、真棒、逆袭、改变人生、冲刺、暴击、满血、血量、惩罚、扣分、排行榜、排名。

**用词的另一种克制**：天文事实的表述必须**可核查**。宁可写"约 1.3 秒"，不写"1.299 秒"；宁可写"直径约 10 万光年（估计值仍在修订）"，不写死一个数。

## 九、世界观附录：可复用的硬事实（写文案时的弹药库）

这些是本作世界设定的"物理依据"，也直接是知识卡的候选：

| 事实 | 数据 | 在设定里怎么用 |
|---|---|---|
| 地球自转周期（恒星日） | 23 小时 56 分 4 秒 | 星球每天自转一圈的科学依据；也解释"一天不是恰好 24 小时" |
| 太阳日 | 平均 24 小时，真太阳日与平太阳日相差 ±16 分 | 解释为什么闹钟时间 ≠ 天文学时间；光照系统的修正项 |
| 晨昏蒙影三级 | 民用 −6°／航海 −12°／天文 −18°（太阳高度角） | **直接是光照相位的定义来源**（见 10 §5.2）；也可做早起窗口分级 |
| 太阳视张角 | 约 0.53° | 晨昏线柔和带约 0.27°（地表约 29 km）→ **晨昏线要锐利**，泛光过宽即失真 |
| 太阳赤纬年周期 | ±23.44° | 昼夜长短与极昼极夜的计算依据 |
| 太阳到地球的光行时间 | 约 8 分 20 秒 | 「你此刻看见的太阳是 8 分钟前的」——用于"延迟入账"的隐喻 |
| 月球距离 | 约 38 万 km（363k–405k，椭圆轨道） | 最短的"远征"刻度 |
| 天数文尺度参考（小行星带） | 谷神星半长轴约 2.77 AU | 用来校准"小星球"的设定：本作星球直径约 1280 km（≈ 月球 1/2.7），远小于任何真实行星 |
| 低轨卫星周期 | 约 90 分钟（ISS ≈ 92 分钟） | 参考数据；本作星港不在轨道上，此项仅用于知识卡 |
| ISS 速度／高度 | 约 7.66 km/s ／ 约 400 km | 入轨速度的直观锚点（知识卡用） |
| 第二宇宙速度 | 约 11.2 km/s | "脱离"= 完成一个长期计划（比喻用，不写进数值） |
| 比邻星距离 | 4.246 光年 | 最近的可命名坐标 |
| 旅行者 1 号 | 1977 年发射，2012 年越过日球层顶 | "长线循环"的人格化对象 |
| 潮汐锁定 | 月球永远同一面朝向地球 | 参考设定；本作星球**不做潮汐锁定**（否则用户看不到全貌） |

> **纪律**：这些数字一旦写进界面，就要按"会被用户去查"的标准核对。设定可以浪漫，数据不能。
