# 03 · 系统与流程
对象层级、机构与计划字段、三种执行方式、结算与中断处理。数值见 [04-数值与养成.md](04-数值与养成.md)，界面见 [06-界面规范.md](06-界面规范.md)。
## 一、对象层级
```text
指挥官 Commander
└── 机构 Agency（领域容器，1..N）：徽记 / 代号 / 域色 / 编制
      └── 计划 Program（周期目标，1..N）
            ├── 周期 7d / 14d / 21d / 30d / 8w / 自定义
            ├── 频率 / 休息日 / 难度档
            ├── 节点 Node（阶段里程碑）
            └── 任务 Mission（可执行动作，1..N）
                  ├── 类型 timed / count / bool
                  ├── 执行方式 点火 / 窗口 / 自由记录
                  └── 执行一次 → Session（航迹，永久）→ XP + RC + 扰动 roll
```
机构是身份，计划是承诺：同一机构先后跑多份计划，换计划不丢领域积累；任务挂在计划下，完成才有归属（「体能署 · 8 周力量 · 第 5 天」）。
## 二、机构系统
### 2.1 预置模板（9 个，一键成立；自定义不限数量）
| 模板代号 | 建议名 | 覆盖领域 | 默认任务 | 执行方式 | 成果系列 |
|---|---|---|---|---|---|
| `MED` | 体能署 | 健身、跑步、拉伸、体重 | 训练一次 / 晨跑 30 分钟 / 拉伸 10 分钟 | 点火 + 窗口 | 行星与卫星 |
| `KIT` | 膳食司 | 厨艺、控糖、饮水、饮食记录 | 做一道新菜 / 2L 饮水 / 不喝含糖饮料 | 自由记录 | 人类航天 |
| `LIT` | 文书记 | 阅读、写作、笔记、复盘 | 读 20 页 / 写 300 字 | 点火 | 深空天体 |
| `EDU` | 学研所 | 备考、专业课、刷题、错题 | 自习 45 分钟 / 错题 10 题 | 点火 | 恒星与星系 |
| `LIN` | 语言局 | 单词、听力、口语 | 听力 15 分钟 / 单词 20 个 | 点火 | 时间与坐标 |
| `WAK` | 晨昏站 | 早起、晨跑、晨间流程 | 07:00 起 / 起床后喝水 | 窗口（闹钟） | 天空现象 |
| `MND` | 静观室 | 冥想、呼吸、情绪记录、睡前流程 | 冥想 10 分钟 / 23:30 放下手机 | 点火 + 窗口 | 天空现象 |
| `CRF` | 创构坊 | 乐器、绘画、摄影、编程 side project | 练琴 30 分钟 / 写代码 45 分钟 | 点火 | 深空天体 |
| `GEN` | 星学苑 | 天文、科普学习、观星 | 看一集科普 / 认一个星座 | 点火 | 全系列（稀有度加权） |
### 2.2 成立流程（3 步，≤60 秒）
① 选模板 / 自定义（默认停在"模板"页，自定义折叠在底部）；② 起名 + 选域色 + 选徽记（三项均有默认值，可整屏跳过）；③ 立第一个计划（提供 3 条推荐计划，含周期与频率，选一条即可）。完成：「挂牌。机构成立。」设施在星球视窗落位，任务面板出现 1 条今日任务。
### 2.3 字段（必填 / 默认 / 上限）
| 字段 | 必填 | 默认 | 上限 |
|---|---|---|---|
| 名称 | 是 | 模板名 | 12 字 |
| 代号 | 否 | 模板代号 | 4 字符（大写拉丁，徽记角标如 `MED-07`） |
| 域色 | 否 | 模板色 | 6 选 1（调色板内取色，保证对比度） |
| 徽记 | 否 | 模板图 | 32×32 像素，8 选 1 |
| 口号 | 否 | 空 | 20 字（只出现在机构档案页，不影响数值） |
| 归档位 | 否 | 自动 | 星图上机构锚点的坐标 |
### 2.4 状态机（5 态）
| 状态 | 触发 | 界面表现 | 数据 |
|---|---|---|---|
| `draft` 筹备 | 成立但未跑过任何任务 | 虚线边框、灰徽记 | 不计入星图 |
| `active` 在轨 | 有进行中计划 | 亮徽记、域色描边 | 正常累计 |
| `idle` 巡航天 | 计划全部完成/暂停，30 天内无执行 | 半亮、标注"巡航" | 保留全部数据 |
| `parked` 停机 | 用户主动暂停 | 灰、保留入口 | 不再累计，历史不动 |
| `archived` 归档 | 用户删除 → 归档 | 收进"档案舱"，可查看 | 永久只读，可一键恢复 |
### 2.5 编制 I0–I4
| 级 | 条件（两个都满足） | 解锁 |
|---|---|---|
| I0 | 成立 | 基础档案 |
| I1 | 累计 10 次执行 且 ≥3 个不同日期 | 徽记可改、口号槽 |
| I2 | 累计 30 次 且 完成 1 份计划 | 域色可改、子机构（拆分为 2 个） |
| I3 | 累计 100 次 且 覆盖 ≥2 类执行方式 | 机构专属成果册、档案页趋势图 |
| I4 | 累计 300 次 且 完成 ≥3 份计划 | 命名权（可命名一个真实天体/设施部件）、旗舰徽记样式 |
编制只解锁表达与展示，不解锁数值倍率：I4 的机构做番茄钟与 I0 给同样 XP（见 [04-数值与养成.md](04-数值与养成.md)）。
## 三、计划与任务
### 3.1 计划 Program 字段
| 字段 | 选项 | 默认 |
|---|---|---|
| 名称 | 自由，≤20 字，现实词优先 | 模板推荐名 |
| 周期 | 7 / 14 / 21 / 30 天 / 8 周 / 自定义 3–365 | 14 天 |
| 频率 | 每天 / 每周 N 次 / 隔天 / 自定义周几 | 每天 |
| 休息日 | 选周几，或"每周自动留 1 天" | 无（主动设置不计中断） |
| 提醒 | 时间 + 通知/无，任务可单独覆盖 | 20:00 |
| 目标量 | 每次分钟数 / 次数 / 布尔 | 25 分钟，可留空 |
| 难度档 | 轻量 / 标准 / 深空，只影响 XP 上限与卡池稀有度，不影响判定 | 标准 |
| 远征节点 | 自动按周期切 2–4 个，节点是里程碑不是关卡 | 开 |
| 中断规则 | 宽容 / 严格（严格档漏一天当周标"需补做"，仍不扣历史） | 宽容 |
### 3.2 任务 Mission 字段（一份计划 1–6 条）
| 字段 | 说明 |
|---|---|
| 名称 | 动词开头（训练一次 / 听 15 分钟 / 做一道新菜） |
| 类型 | `timed` 定时 / `count` 计数 / `bool` 布尔 |
| 目标量 | 分钟 / 个数 / — |
| 排期 | 周几 + 一天内时段 |
| 执行方式 | 点火 / 窗口 / 自由记录 |
| 最小完成线 | 达到 60% 即算成功（可关），如 18 分钟算完成 |
最小完成线是反脆弱设计：状态差的日子做完 60% 也算入账，周报标注"达标 / 及格线达标"。任务从机构的主题列表里选（主题 = 现实动作 + 科学知识课程序列），字段由主题预填仍可改，主题与卡片见 [09-内容库-知识卡.md](09-内容库-知识卡.md)。
### 3.3 三条推荐（降低配置负担）
成立「体能署」→ ① 21 天 · 每天动 30 分钟　② 8 周 · 每周 3 次力量　③ 14 天 · 每天拉伸 10 分钟　④ 自己立一份
每条推荐计划自带 2–4 条任务与排期。判据：>50% 用户走到"自己立一份"说明推荐质量不足；<10% 用户采用任何推荐说明模板不像他们自己的话。
## 四、执行层
### 4.1 点火 IGNITION · 番茄钟
| 项 | 规则 |
|---|---|
| 时长档 | 15 / 25 / 45 / 60 分钟 + 自定义 1–180 |
| 开始 | 一个按钮，无二级确认，开始即锁定计时 |
| 计时与后台 | `elapsed = now − start`，不累加 tick；前台服务保活 + 通知栏常驻；允许息屏，回前台按时间戳续算 |
| 中断 | 中止 → `aborted`，给 30% XP（无扰动、无卡），标注未完成；退出 App 不自动中止 |
| 完成与表现 | `elapsed ≥ target`（或 ≥ 最小完成线）→ `success`；入轨动画 ≤600ms → 结算抽屉（XP + 可能一张卡 + 扰动） |
| 连续专注 | 任务串（25+25 连打），每段独立 Session，不叠加 XP 递减 |
| 不做 | 不锁其他 App、不做强制专注、不做"专注失败扣建筑"类惩罚 |
### 4.2 发射窗口 WINDOW · 闹钟
| 项 | 规则 |
|---|---|
| 设定 | 时刻 + 重复（工作日/周末/自定义周几）+ 贪睡次数 0–2 |
| 触发 | 系统精确闹钟 + 全屏来电式界面（拖刻度 / 2 位数加法解除，二选一） |
| 记录窗 | 解除后 30 分钟内确认"我起床了"→ `window_confirmed` |
| 迟确认 | 30–120 分钟 → `window_late`，仍算成功，XP 减半 |
| 过期 | 未确认 → `window_missed`，只标"未确认"，不倒扣历史、不发愧疚通知 |
| 晨昏蒙影分级 | 民用 −6° / 航海 −12° / 天文晨 −18°（按经纬度算真太阳时）；天文晨之前解除 → 点亮晨星 |
| 承接与周末 | 确认后直接跳到该机构今日第一条任务；休息日自动跳窗，写明「今天没有窗。」 |
### 4.3 自由记录 LOG
| 项 | 规则 |
|---|---|
| 适用 | 护肤、饮水、记账、服药、"今天做了"这类不需时长的动作 |
| 交互 | 任务面板一行一个勾，两次点击内完成；支持小组件/快捷指令 |
| 反馈 | 轻量 toast，无动画、无结算抽屉 |
| XP | 固定低值（见 [04-数值与养成.md](04-数值与养成.md)），不参与稀有扰动 roll |
### 4.4 执行方式选择建议（写在模板里，用户可改）
| 现实动作 | 推荐方式 |
|---|---|
| 自习、刷题、写作、练琴、力量训练 | 点火（时长即质量；力量也可自由记录） |
| 跑步 | 点火 或 外部运动数据（与运动 App 打通留 P5） |
| 早起 | 窗口（只有闹钟能判定） |
| 护肤、饮水、服药 | 自由记录（无需时长） |
| 阅读 | 点火 或 计数页数（因人而异） |
| 冥想 | 点火 15 分钟档 |
## 五、结算与入账（四层信息 + 五条规则）
```text
① 判定   入轨 / 及格线 / 中止
② 归属   体能署 · 8 周力量 · 第 5 格
③ 确定   推进值 +40
④ 随机   扰动 0.6s roll → 研究成果入库 G2 →「地球的一天其实不是 24 小时」[看全文] [收下]
```
| 规则 | 内容 |
|---|---|
| 必给优先 | 推进值一定显示，扰动一定在后面；不出现"完成但什么也没给"的空白结算 |
| 知识卡节流 | 同一 Session 最多 1 张；同一天最多 3 张；未读卡进"待归档"，不堆超 5 张 |
| 递减可见 | 当日第 4 次起显示 `+12（今日递减）`，明说，不做隐藏衰减 |
| 无强制互动 | 不要求"看完知识才能继续"，`[收下]` 永远一秒可达 |
| 可静音 | 设置里关掉随机扰动 → 结算只剩 ①②③，界面不留灰位 |
## 六、中断、暂停、恢复（三段式 + 三条禁止 + 四条允许）
```text
① 漏（自动，不弹窗、不推指责）：「这次没记上。」「之前 59 次都还在。」
   XP 不回退、星图不减少、等级不降级、设施不破败
② 补（用户主动，可以永远不做）：「补做」按钮在停机 ≤7 天的计划卡（基地面板 L2）
   恢复当期连续性，夺回当周节点进度的 50%（XP 不追溯）
③ 回来（隔了很久）：「轨道过去了。星港还在。」+「停机 22 天 · 历史 148 条 · 无删除」
   动作只给一个入口：[排今天的事]
```
| 类别 | 条 | 说明 |
|---|---|---|
| 禁止 | 写"你已连续中断 N 天" | 把中断变成负债；改为"停机 N 天 · 历史无删除" |
| 禁止 | 发"好久不见，我们想你了"推送 | 思念式推送是羞耻感的包装 |
| 禁止 | 等级/建筑回落 | 一次回落足以让用户删除 App |
| 允许 | 主动留白 | 设置休息日 → 该日不计为漏，周报单列"计划休整" |
| 允许 | 中途改频率 | 每周 5 次改 3 次，历史不重算，改动作当期生效 |
| 允许 | 分段重启 | 同一计划"重新起算一个周期"，上一段归档为"上一次远征" |
| 允许 | 曲线重置 | 周报提供"我不看连续天数"开关，连续数隐藏，只留总量与趋势 |
## 七、核心用户流程
主界面为顶部星球视窗 + 分段选择器（计划 / 任务 / 基地），详见 [06-界面规范.md](06-界面规范.md)、[07-三维视窗.md](07-三维视窗.md)。F1 首次到第一次成功（≤5 分钟，激活关键）：
```text
启动 → 序章 4 屏（第 1 屏即真实三维星球）→ [成立机构] → 选模板「体能署」→ 起名（默认）→ 选一条推荐计划
→ 设施在星球视窗落位亮"营建"；任务面板出现 1 条今日任务
→ [开始专注] → 25 分钟（演示可 90 秒）→ 入轨动画 → 设施脉冲、信号灯转绿 → 结算：XP + 第一张知识卡（T0 必出）→ 基地页星图亮起第一颗
```
判据：完成率 ≥70%、耗时中位数 ≤4 分钟；若流失集中在起名/选色/选址，三项合并一屏且可整屏跳过。
F2 每日主循环：打开 → 星球视窗（顶栏相位 + 等级；决策 AI 一句话）→ 看设施信号灯（待办 = 琥珀慢闪）→ 点设施 → 舱窗面板 → [开始专注] → 完成 → 设施亮一格、灯转绿 → 全部完成时决策 AI 一句「今天的航程走完了。」（不催促做更多）。快捷路径：切「任务」标签直接勾选，两形态共享数据与筛选状态，切换 ≤320ms。
F3 早起闭环：07:00 全屏窗 → 拖刻度解除 → 直接跳到当日第一条任务 → 07:20 前完成点火 → 结算 + 晨星标记（天文晨 −18° 之前）→ 回星球视窗时光照已推进到 dawn → dusk 相位。
F4 计划节点结算：最后一个 Session 成功 → 节点结算页（长版，唯一允许长文案的屏）→ 显示周期内次数/分钟/达标率/漏几格/休息日 → 发放成果卡（节点保底 1 张，难度越高稀有度上限越高）+ 徽记 + 称号 → 设施加建动画、地块点亮一格、星图新增一段航迹 → 下一段邀请（可拒绝，无副作用）。
F5 长期无进展（连续 2 周未达标）：周报出现「这两周的节奏比之前松。」（只陈述），决策 AI 给 3 个可一键采纳的动作：[把频率降一档] [换一份计划] [什么都不改，继续]。
绝不出现"再坚持一下哦"。
F6 删除 / 归档：点设施 → 面板 L2' → 归档 → 「记录留着。随时回来。」设施做落光动画，保留低亮度轮廓在星球上不动，可一键恢复。
不做挽留弹层，不做"你确定要失去所有进度吗"式恐吓。
## 八、系统边界一览
| 系统 | 有 | 没有 |
|---|---|---|
| 三维视窗 | 球体、相机固定位姿、真实昼夜光照、设施锚点、HUD、舱窗面板 | 自由飞行、地形起伏、实时阴影、文字进场景、多角色 |
| 机构 | 领域容器、模板、自定义、编制、设施映射、归档 | 组织协作、共享、权限 |
| 计划 | 周期、频率、休息日、节点、难度档、宽容/严格 | 甘特图、依赖关系、里程碑排程、项目 |
| 任务 | 三种类型、三种执行方式、最小完成线 | 子任务树、标签系统（v1 只做机构归属）、优先级 |
| 执行 | 计时、闹钟、记录、后台保活 | 白噪音（P5）、网站屏蔽、强制专注 |
| 奖励 | XP、RC、知识卡、扰动、徽记、命名权 | 货币、商城、消耗、抽卡付费 |
| 养成 | 公共设施 8×5、机构设施、涂装、徽记、舱内视图 | 体力、等待墙、衰败、战斗 |
| 决策 AI | 状态播报、可执行建议（可采纳/拒绝）、三档人格 | 替用户做决定、自动改计划、催促推送 |
| 数据 | 星图、周报、趋势、导出 | 云账号（v1）、社交、分享榜单 |
