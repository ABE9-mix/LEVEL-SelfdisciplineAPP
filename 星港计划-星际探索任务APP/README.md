# 星港计划 STARPORT · 星际探索主题任务计划 APP

> **一句话**：你是一枚航天中心的指挥官。你成立的每个机构、启动的每次任务，烧的都是你在现实里真正花掉的时间；换来的，是一颗会亮起来的小星球，和一片越来越清楚的星空。

代号 **STARPORT（星港计划）**。状态：策划案 v0.2（三维地图方向已锁定，待设计稿）。

## v0.2 方向变更（本轮锁定）

> 原 v0.1 是"列表为主界面 + 甜点化装饰"。本轮按新方向重构。

| # | 决策点 | 结论 |
|---|---|---|
| 1 | 主界面形态 | **双形态**：三维星球地图为主 + 今日列表一键切（同一路由的视图开关） |
| 2 | 光照 | **跟随手机真实时间 + 当地日出日落**（晨昏线是真的，六相位驱动 HUD 主题） |
| 3 | 引导人格 | 原「领航员」→ **决策 AI**：有人味的副手（有判断、可建议、偶尔短吐槽，每日配额 ≤2 次，三档可调） |
| 4 | 设施交互 | **地图内弹出舱窗面板**，地图保持可见；L1 设施 → L2 计划 → L3 任务，最多 3 层 |
| 5 | 世界设定 | 新增世界事实 E：**星球小到可以被看遍**（星港停泊在小星球地表，不再在地球轨道） |
| 6 | 导航 | 由 5 tab 改为 **4+1**：今日 / 星图 / 复盘 / 我的 + 中央「开始专注」主按钮（机构不再占 tab，就在地图上） |
| 7 | 相机 | **固定位姿 + 球体自转**（不做相机环绕飞行）；FOV 35°，球心距 3.33R，可见球冠 72.5°、占球面 35% |
| 8 | 动态星空 | 六相位驱动；其中**约 300 颗真实亮星可点**，点开即该天体的知识卡（背景层成为知识入口） |

**变更理由一句话**：列表告诉你"今天做什么"，星球告诉你"你已经走了多远"——积累必须看得见，早起则因为真实天光而有了真实对照物。

## 六条设计底线（先说清楚什么不做）

| # | 底线 | 具体含义 |
|---|---|---|
| 一 | **行动先于表达** | 游戏层不给"无现实动作的产出"。无挂机收益、无签到即得、无可刷空任务、无离线收益 |
| 二 | **记录只增不减** | 等级、航时、知识卡、星图、已完成的现实记录永不回退。设施不停机破败、地块不变暗 |
| 三 | **随机不改变难度** | 随机量只作用于**呈现与奖励稀有度**，不改变任务是否判定成功、不改变现实目标（新增世界法则六：噪声不改航向） |
| 四 | **养成不做义务** | 无体力、无等待墙、无衰败、无货币。扩建只看门槛，升级只解锁表达（不影响 XP 单价/判定/概率） |
| 五 | **不比较** | 无排行榜、无"超过 xx% 指挥官"、无社交 PK。对照对象只有自己的历史 |
| 六 | **概率公开** | 彩蛋真实概率在设置里可查，保底计数可见。不做暗箱、不做限时 FOMO、错过不追回 |
