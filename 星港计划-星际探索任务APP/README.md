# 星港计划 STARPORT · 星际探索主题任务计划 APP

> **一句话**：你是一枚航天中心的指挥官。你成立的每个机构、启动的每次任务，烧的都是你在现实里真正花掉的时间；换来的，是一座会亮起来的星港，和一片越来越清楚的星空。

## 六条设计底线（先说清楚什么不做）

| # | 底线 | 具体含义 |
|---|---|---|
| 一 | **行动先于表达** | 游戏层不给"无现实动作的产出"。没有挂机收益、没有签到即得资源、没有可以刷的空任务 |
| 二 | **记录只增不减** | 等级、航时、知识卡、已完成的现实记录永不回退。中断只影响"未结算的加成" |
| 三 | **随机不改变难度** | 随机量只作用于**呈现与奖励稀有度**，不改变任务是否判定成功、不改变现实目标本身 |
| 四 | **养成不做墙** | 无体力值、无等待墙、无"星港衰败"。升级不影响任务成功率，只解锁表达与展示位 |
| 五 | **不比较** | 无排行榜、无"超过 xx% 的指挥官"、无社交 PK。对照对象只有自己的历史 |
| 六 | **概率公开** | 彩蛋的真实概率在设置里可查。不做暗箱、不做限时 FOMO、错过不追回 |

## 命名候选（待定）

| 候选 | 理由 | 风险 |
|---|---|---|
| **星港 STARPORT** | 中心即产品，名词短、可延展（星港扩建／回港） | 与机场语义撞 |
| **光年之外 Beyond** | 情绪大，适合传播 | 泛、无主体感 |
| **指挥官命令台** | 角色感强 | 太长 |
| **ORBIT 轨道** | 干净、有"周期"含义 | 已被大量产品占用 |
