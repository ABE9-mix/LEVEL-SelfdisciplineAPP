# 06 · 界面规范

> 主界面采用三标签 IA：计划 / 任务 / 基地。顶部星球视窗固定，导航用顶部分段选择器，不使用底部 TabBar。

## 一、主界面结构
```
┌──────────────────────────┐
│ 状态栏 47                 │
├──────────────────────────┤
│ 顶部 · 星球视窗 358×200   │
│ 星球·设施动画·标题 [设置][账户] │
├──────────────────────────┤
│ [计划][任务][基地] 分段44 │
├──────────────────────────┤
│ 主内容区 358 宽，可滚动    │
├──────────────────────────┤
│ Home 指示条 34            │
└──────────────────────────┘
```

## 二、导航与层级
```
主页面（计划 / 任务 / 基地，横向滑动切换）
├─ 计划 → ★ 计划详细设置
├─ 任务 → ★ 任务详细设置 → ★ 任务进行页面 → ★ 任务结算页面
├─ 基地 → ★ 资源查看页面
├─ 右上角设置 → ★ 设置页
└─ 右上角账户 → ★ 账户个性化页
```
二级页以全屏或面板呈现；返回保留当前标签与滚动位置。

## 七、动效预算
| 场景 | 时长 | 曲线 |
|---|---|---|
| 分段切换 | 320ms | ease-in-out |
| 面板展开 | 240ms | ease-out |
| 设施脉冲 | 600ms | ease-out |
| 晨昏推进 | 1200ms | ease-in-out |
| 锚点点击 | 160ms | ease-out |
| 结算展开 | 280ms | ease-out |
| T1 微光 | 400ms | linear |
| T4 彗星 | 2400ms | ease-out |

约束：非用户触发动效默认 ≤1.2s，T4 彗星掠过按表 2400ms；同屏不并行两个以上动效；`prefers-reduced-motion` 时全部降级为淡入淡出。

## 八、无障碍与降级
| 项 | 做法 |
|---|---|
| 纯列表模式 | 星球视窗不可用或用户关闭时，列表升为主视图，全部功能可达 |
| 动态字体 | 支持系统字号放大到 130%，HUD 与正文同步放大重排 |
| 对比度与色盲 | 文字对背景 ≥4.5:1；状态不只靠颜色：待办闪烁、完成常亮加勾、停机灭灯 |
| 减弱动态与读屏 | `prefers-reduced-motion` 关自转、脉冲、彗星；三维视窗提供等价文本：「星球视窗，5 个机构，今日完成 4 / 6」 |
