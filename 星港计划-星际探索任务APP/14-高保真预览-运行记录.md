## 踩坑（本轮）

| 现象 | 正解 |
|---|---|
| 批量删文字时用宽松正则 → 屏标题也被删 | **删之前先分类打印并计数**，保留名单要显式枚举 |
| `inspect` 的坐标在 `j.raw.x`，不是 `j.x` | 一律读 `raw` |
| `component instantiate` 不能传 COMPONENT_SET | 必须传具体变体的 COMPONENT id |
| `-x/-y` 是父级局部坐标 | 不要加屏原点 |
| `node set --fill` 对部分色值回滚 | 用 `node bind`（`-c` 传集合**名称**）或 PAINT 样式 + `--field fill` |
| 正则 `(\d+(?:\.\d+)?)` 的 `(?:...)` 不计数 | 组号要数清楚，解析后断言 |
| **实例内子节点 id 是 `I实例id;源id`** | `node set-text` 对它无效。**必须给组件加 TEXT 属性**，用 `component prop set` 改 |
| `component prop add` 后属性是 `unbound` | 还要 `component prop bind <setId> <propFullName> <textLayerId>`，`prop list` 显示 `wired` 才算接好 |
| **`node set --stroke` 必回滚** | 描边改不了。需要区分可选态时**改用 EFFECT 样式**（凸起/凹下）拉开层次 |
| `node set --stroke` + `--stroke-width` 同写 | 更会回滚，两条路都别走 |
| `component combine` 会把横排变体直接并成集合 | 想做**单一组件**就别 combine，直接 `node to-component` 包容器帧 |
| `to-component` 的返回要用 `Converted:\s*(\d+:\d+)` 取 | 直接取第一个 id 会拿到容器旧 id |
| `node tree --depth 1` 对屏只返回屏本身 | 取子节点要 `--depth 2`，且缩进是 **2 空格** |
