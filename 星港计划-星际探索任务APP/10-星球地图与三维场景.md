# 10 · 小星球地图与三维场景

> **本文是全案的空间层规范。** 产品的主界面不再是列表页，而是一颗可以旋转的小星球；机构即设施，锚定在球面上；计划与任务的编辑从设施点进去。
>
> 本章只定**方向与规格**，视觉稿由设计侧后续绘制（见 §九 交付清单）。

---

## 一、这个方向解决了什么

原始形态（列表 + 甜点化装饰）的问题：**进度是一串数字，用户难以感知"我的时间去了哪里"**。三维星球地图把抽象积累变成空间：

| 抽象量 | 空间化表达 |
|---|---|
| 指挥等级 | 星港整体亮度与舱段数量 |
| 机构（领域） | 球面上的一座建筑（设施） |
| 机构活跃度 | 该设施的**灯光强度与动态**（在营建/在运行/停泊） |
| 计划进度 | 建筑自身的营建进度（脚手架 → 主体 → 亮灯） |
| 今日状态 | 全星球光照相位（黄昏/夜/极夜）+ 设施的实时闪烁 |
| 长期积累 | 球面被点亮的地块数量（星图只增不减的空间版本） |

**一句话**：列表告诉你"今天做什么"，星球告诉你"你已经走了多远"。

---

## 二、世界设定的调整：小星球

原设定是"轨道上的星港"。为了支持"一颗可以旋转看全貌的星球"，世界设定调整为：

> **星港不是停在地球轨道上的空间站，而是停泊在一颗小星球上——它的直径只有真实行星的极小一部分，绕一颗稳定的恒星公转。** 星港的设施分布在这颗星球的表面，从高空看，它是一颗你能在几分钟内看遍的球。

这不是设定让步，而是**新增一个设定事实**（世界事实 E）：

| # | 世界事实 | 内容 | 对应设计 |
|---|---|---|---|
| **E** | **小星球可以被看遍** | 星球很小，小到你的机构能各自占据一片地面；星港随时可以从高空俯瞰它。看得见全貌，才谈得上"这是我的"。 | 三维球体地图；设施锚点；可旋转可缩放 |

**为什么不与"星际探索"冲突**：探索的对象不是星球本身，而是**球外的深空**——星图（知识卡、命名权、观测台解锁的远方天体）才是探索的目的地。星球是你的**基地**，深空是你的**成果**。空间关系因此干净：内圈 = 你的积累，外圈 = 你学到的东西。

**命名沿用**：星球本身可被指挥官命名（见 05 个性化），默认名 **「晨昏」**（因为它的开发锚点位于晨昏线附近——见 §五光照）。

## 三、相机规范（固定放大球面，靠球体自转呈现全貌）

这是本方向最核心的一条技术决策：**相机不做环绕飞行，只做固定位姿 + 球体自转**。

| 项 | 规格 | 理由 |
|---|---|---|
| 相机类型 | 透视相机，FOV **35°** | 接近长焦，球体收边平缓，几何形变小；比广角更适合读建筑 |
| 球体归一化半径 | `R = 1` | 所有距离以 R 为单位 |
| 球心距相机 | **≈ 3.33 R**（相机距球面 ≈ 2.33 R） | 竖屏下方球体直径为屏高 95%，上下留出 HUD 安全区 |
| 可见球冠半角 | **θ = 72.5°** | 相机在有限距离时比"无限远"多看到约 17.5° 的边缘 |
| 可见球面占比 | **35%** | 一屏看到约 1/3 星球，够读全局又不至于变成平面 |
| 相对球心俯角 | 默认 **22°**（可 10°–40°） | 22° 是"建筑可读"与"星球可感"的折中；纯 0° 像地图，>40° 像俯瞰沙盘 |
| 地平线透视压缩比 | **0.30** | 边缘设施会被明显压扁 → **锚点布局必须做透视避让**（§六） |

### 3.1 旋转模型

```
用户可以做的：                          系统可以做的：
  · 双指/滚轮：绕 Y 轴自转（经度）        · 自动缓慢自转（空闲 8s 后启动，0.6°/s）
  · 单指拖动：同上（横向）                · 转到设施时减速并停（吸附，见 3.3）
  · 上下拖动：俯角 10°–40°（不越极点）    · 任务完成时轻微前倾 1.5°（一次"点头"）
  · 双指捏合：相机距 2.6R–4.2R            · 结算高光时球体自转对齐该设施
```

**为什么不让相机绕行**：相机绕行会产生"我在飞"的错觉，同时让 HUD 与地面的参考系不停变化，用户容易迷失；球体自转则始终保持"我停在星港上、看着星球转"的稳定关系，符合"基地"的心理模型。

### 3.2 相机状态机

| 状态 | 触发 | 表现 | 退出 |
|---|---|---|---|
| `idle` 空闲 | 默认 | 缓慢自转，HUD 低频更新 | 任意输入 |
| `browse` 浏览 | 用户拖动 | 自转跟手，惯性衰减 | 松手 8s 后回 idle |
| `focus` 聚焦 | 点击设施 | 自转对齐 + 拉近至 2.9R + 舱窗面板弹出 | 关闭面板 |
| `exec` 执行 | 启动点火/闹钟 | HUD 收起，星球降亮度至 25%，进入计时态 | 计时结束/中止 |
| `result` 结算 | 入轨成功 | 该设施脉冲 → 星球"晨昏推进"一圈 → 卡面浮出 | 关闭结算 |
| `cold` 冷启 | 无网/低电 | 静态球体贴图（无动态星空） | 恢复 |

### 3.3 吸附与防误触

| 问题 | 处理 |
|---|---|
| 设施太多，点不准 | 命中区 = 视觉尺寸 **1.8 倍**（最小 44×44 pt，符合触控规范） |
| 背面设施被误点 | 仅 `dot(N, V) > 0.15` 的正面设施可点；背面设施以"暗点"显示，点击时提示"转到这颗星球背面" |
| 旋转时误触 | 拖动位移 > 8 pt 即判定为旋转，不触发点击 |
| 边缘压扁导致错觉 | 距地平线 < 8° 的设施自动上浮标签（引线），不依赖模型本体 |
| 密集区（同纬度多机构） | 设施自动沿纬度带错位排布，保持最小 2.5° 经度间隔 |

**锚点容量（实测计算）**：全球按 12° 间距可容纳 **约 91 个**不重叠锚位；单屏可见面约 **32 个**。即使用户建满 20 个机构，也不会拥挤；超过 12 个时启用"纬向分层 + 标签优先级"。

## 四、星球本体规格

| 项 | 规格 |
|---|---|
| 几何 | 球体，细分按档位（见下）；**不做地形高度**（保持"小而完整"的可读性） |
| 半径 | 1 R（归一化）；换算演示单位 ≈ 640 km（约月球半径的 1/2.7） |
| 表面 | 一张等距柱状投影（equirectangular）**基础贴图 2048×1024** + 分层材质（陆地/岩层/冰盖/网格测绘线） |
| 网格测绘线 | 极细经纬线，alpha ≤ 0.12；仅在"测绘模式"提高亮度（用于找设施） |
| 云层 | 可选一层，独立球体 R+0.012，半透明，缓慢反向自转（可关闭以省电） |
| 大气散射 | 边缘辉光（Fresnel 近似），厚度 ≤ 0.04R，颜色随光照相位变化 |
| 地块点亮层 | 已激活设施的地面网格（8×8 小格）由暗转亮，逐格累积，**只增不减** |
| 档位 | **高**：细分 128×64 + 云层 + 大气 + 动态星空<br>**中**：64×32 + 大气（无云）<br>**低**：32×16（如折叠屏低电/老设备）+ 静态星空，自转降频至 30fps |

**为什么不做真实地形起伏**：地形会挡住设施、让锚点定位困难，且显著增加美术成本。设计目标是"看得清我的东西在哪"，不是"做一颗真实行星"。

## 五、光照系统（跟随真实时间 + 当地日出日落）

光照是这张地图的**主要信息通道**，不是装饰。规则：

### 5.1 光源模型（真实天文驱动）

| 输入 | 来源 | 用途 |
|---|---|---|
| 当前 UTC 时间 | 系统时钟 | 计算太阳位置 |
| 设备经纬度 | 定位权限（**可选**，拒绝则用"手动城市"） | 计算当地真太阳时与日出日落 |
| 时区与经度修正 | 系统时区 + 经度 | 真太阳时 = 平太阳时 + 时差修正（±16 分钟内） |
| 太阳赤纬 | 按日期算（±23.44° 年周期） | 决定昼夜长短与极昼极夜 |

**太阳方向角直接驱动星球着色器**：星球上朝向太阳的表面被照亮，背向的进入夜面。因此：

- **星球的昼夜分界（晨昏线）是真实的**（不是贴图翻转）。用户在 20:00 打开，看到的晨昏线位置与当天的真实情况一致。
- 太阳对地表的张角约 **0.53°**，因此晨昏线柔和带约 **0.27°**（地表约 29 km 尺度）——**晨昏线应当是锐利的**，泛光过宽会失真。这是美术容易犯的错。

### 5.2 光照相位（六态）

| 相位 | 触发条件（当地真太阳时 / 太阳高度角） | 星球表现 | 星空表现 | 情绪 |
|---|---|---|---|---|
| **晨** `dawn` | 太阳高度 −6° → 0°（民用晨光） | 半球偏冷蓝，边缘金橙，晨雾层 | 星渐隐，东侧泛白 | 开始 |
| **昼** `day` | 高度 > 0° | 全面亮，云层可见，设施灯光关闭 | 星空不可见（仅留稀薄） | 执行 |
| **昏** `dusk` | 高度 0° → −6° | 暖橙压过蓝，长影 | 星开始出现 | 收束 |
| **夜** `night` | 高度 −6° → −18°（航海暮光） | 主色深蓝，设施成为唯一光源（点光） | 银河带清晰 | 专注/静心 |
| **深夜** `deep` | 高度 < −18°（天文夜） | 极暗，仅有设施灯与测绘线 | 银河 + 黄道带微光 | 睡前进度 |
| **极夜/极昼** `polar` | 高纬度季节性 | 全天不切换昼夜；极昼时星空为"稀薄蓝" | 特殊 | 彩蛋级罕见视觉 |

**与产品机制绑定（关键）**：

| 相位 | 产品含义 |
|---|---|
| `dawn` | **发射窗口时段**：窗口任务在此相位有特殊的"过境轨线"动画 |
| `night` / `deep` | **静观室、文书记、睡前流程**的推荐时段；设施灯光成为主要视觉 |
| `day` | 默认工作时段；HUD 使用高对比（亮底暗字切换） |
| 相位切换瞬间 | 一次性过渡动画（≤1.2s），每天最多播 1 次，不重复 |
| 用户在看星球时跨越晨昏线 | 决策 AI 短句一次：「天黑了。」（每天仅一次，避免噪音） |

**"跟真实时间"的收益**：早起用户在真实天光里看到自己的星球也在日出，这个同步本身就是最好的正反馈——**不需要任何虚拟奖励**。这也是把"早起"从意志力问题变成"与世界对齐"问题的关键设计。

**一致性的代价与处理**：

| 问题 | 处理 |
|---|---|
| 用户在极夜地区长期看不到昼夜变化 | 提供"跟随当地时间 / 固定演示时间"二选一（默认前者） |
| 用户白天用 App，看不到夜晚的星球 | 星图/复盘页可播放"当日光照回顾"（把一天的光照压缩成 6 秒） |
| 时差、旅行 | 跟随系统时区自动更新，切换时播一次节气过渡 |
| 拒绝定位 | 用城市选择器（默认取系统时区对应主要城市），误差 <30 分钟 |

## 六、设施（机构）在地图上的呈现

### 6.1 设施 = 机构，一一对应

| 机构概念 | 地图表达 |
|---|---|
| 机构类型（体能署/膳食司/观测台…） | 建筑**形制族**（见 6.2） |
| 机构编制 I0–I4 | 建筑尺寸与复杂度（基础舱 → 加建 → 塔标 → 天线阵 → 旗舰） |
| 机构状态 | 灯光与动态（下表） |
| 计划进度 | 建筑上的**营建脚手架**逐段拆除，主体逐段亮灯 |
| 今日是否有任务 | 建筑顶部信号灯闪烁（待办=琥珀慢闪；已完成=绿常亮；停机=灭） |
| 领域色 | 建筑主色调（域色，6 选 1，见 05） |
| 徽记 | 贴在建筑正面的一块铭牌（可放大查看） |

### 6.2 八类形制族（与机构模板对应）

| 机构 | 形制关键词 | 剪影特征 |
|---|---|---|
| 体能署 | 低矮宽阔、训练场、能源塔 | 横向体量 + 两根支撑塔 |
| 膳食司 | 穹顶温室、暖色灯、管道 | 半球罩 + 蒸汽管道 |
| 文书记 | 高窄档案塔、竖排窗 | 竖向细塔 + 密集窗格 |
| 学研所 | 方正中庭、环形廊 | 回字形 + 中央天井 |
| 语言局 | 抛物面阵列、细长天线 | 多个盘状天线 |
| 晨昏站 | 时钟塔 + 长阴影板 | 竖直刻柱 + 巨大表盘 |
| 静观室 | 薄壳、涉水池、低照度 | 浅穹 + 水面反射 |
| 创构坊 | 不规则拼接、外露结构 | 多立方体错落 + 桁架 |
| 星学苑 | 观测穹顶可开合 | 大型天文穹顶 + 缝隙开启动画 |

**美术规格（三档 LOD）**：

| LOD | 距离 | 三角面预算 | 说明 |
|---|---|---|---|
| L0 近 | 相机距 ≤ 3.0R 或聚焦态 | 6k–12k 面 | 可读细节（窗、桁架、铭牌） |
| L1 中 | 3.0–3.6R | 1.5k–3k 面 | 主体 + 剪影 |
| L2 远 | > 3.6R | 200–500 面 | 仅剪影 + 发光块 |

**屏幕占比（实测换算）**：设施模型高 0.12R 时，在默认距离下约占屏幕 **48 pt**（DPR3 = 145 px）——足够展示剪影与信号灯，但**不足以读文字**。因此：**文字一律不进三维场景**，只在标签引线、面板与 HUD 上出现。这条是硬规则，能避免 90% 的三维 UI 可读性事故。

### 6.3 设施五态视觉

| 状态 | 灯光 | 动态 | 说明 |
|---|---|---|---|
| `building` 营建 | 脚手架灯（暖黄，单点） | 缓慢旋转的吊臂 | I0→I1 阶段 |
| `running` 在营 | 域色主灯 + 窗光 | 信号灯慢闪，偶尔有"人影"剪影（极低成本动画） | 有进行中计划 |
| `done_today` 今日已达成 | 绿灯常亮 + 轻微上冲光柱 | 无闪 | 完成态，避免继续催促 |
| `idle` 巡航 | 灯光 40% | 极慢呼吸（4s 周期） | 计划空窗 |
| `parked` 停机 | 灭灯，保留轮廓 | 无 | 用户主动暂停；**地图上依旧在，位置不变** |

**重要**：停机/中断的机构**不会变暗到消失、不会被"破败化"**。地图上没有"废墟"这套表达——违反法则三的视觉都不做。

## 七、主界面 HUD（浮在三维地图上的状态层）

主菜单**退化为浮动 HUD**：只负责"当前状态提示"，不负责编辑。编辑入口一律是地图设施。

### 7.1 HUD 分区

```
┌──────────────────────────────────────────────┐
│ ① 顶栏（安全区下 12pt）                       │
│   [相位图标] 晨昏 · 06:12        Lv.12 ▓▓▓░░ │  ← 左：光照相位 + 当地时间
│   Decision AI 一句话（≤18 字，可折叠）        │     右：等级与推进值细条
├──────────────────────────────────────────────┤
│                                              │
│                 （星 球 本 体）               │
│            设施模型 + 标签引线 + 信号灯        │
│                                              │
│ ④ 浮标（跟随聚焦设施）：                       │
│    体能署 · 8周力量 · 第5/24格   [进入]        │
│                                              │
├──────────────────────────────────────────────┤
│ ③ 底栏（安全区上 12pt）                       │
│   [今日]  [机构]  [星图]  [复盘]  [我的]      │  ← 4+1 图标导航
│   ② 中央主按钮：「开始专注」44pt 圆形          │  ← 悬浮于底栏上缘，永远可达
└──────────────────────────────────────────────┘
```

### 7.2 HUD 组件规格

| 区 | 组件 | 规格 | 数据源 |
|---|---|---|---|
| ① 左 | 相位徽标 | 24×24 图标 + 时间文本（15pt） | 光照相位 / 当地真太阳时 |
| ① 右 | 等级与推进值 | `Lv.12` + 细条 60×4（圆角 2） | XP 累计 / 本级门槛 |
| ① 中下 | 决策 AI 一句话 | 15pt，最多 2 行，8 秒后自动淡出 | 见 02 §3.2 语气库 |
| ② | 主按钮 | 56×56 圆形，底部吸边，双状态（开始/暂停） | 今日排序第一条任务 |
| ③ | 底栏 | 5 个 28×28 图标 + 11pt 标签，高 56 + 安全区 | 导航 |
| ④ | 浮标 | 宽 ≤ 300pt 胶囊；仅聚焦态出现 | 聚焦设施 + 其当前计划 |
| — | 今日摘要 | 右上角小胶囊 `4/6` | 今日完成比（点击切今日列表） |

### 7.3 HUD 的可读性硬规则

| 规则 | 值/做法 |
|---|---|
| 文字对比背景 | 至少 4.5:1；HUD 一律带**半透明毛玻璃底 + 1px 内描边**，不依赖背景亮度 |
| 亮色相位（`day`） | HUD 自动切"亮底暗字"主题；暗相位切"暗底亮字" |
| 文字永不投射到球体表面 | HUD 固定在屏幕空间，避免透视形变 |
| 动态遮挡 | 球体亮部面积大于 40% 屏幕时，HUD 底色加深 12% |
| 触控最小尺寸 | 44×44 pt |
| 相位切换过渡 | ≤1.2s，且不遮挡可点区域 |

## 八、舱窗面板（点设施后的编辑形态）

**地图内弹出，地图保持可见**——不切全屏、不离开场景。

### 8.1 形态规格

| 项 | 规格 |
|---|---|
| 位置 | 从设施锚点向屏幕内（上/下）展开的卡片；默认底部 2/3 高度 |
| 尺寸 | 宽 358（竖屏安全边距 16×2）；高 40%–72%（可拖拽） |
| 背景 | 同一帧内渲染的**模糊球体快照**（不是纯色），保留空间语境 |
| 关闭 | 下拖 / 点地图空白 / 右上 ×；关闭后镜头退回 `idle` 位姿 |
| 多面板 | 不支持堆叠；进更深层级用**面板内推入（push）**，最多 3 层 |
| 动画 | 展开 240ms（ease-out）+ 设施微前移 0.02R |

### 8.2 面板层级（从设施出发的三层）

```
L1 设施面板（机构主页）
    头部：徽记 + 机构名 + 编制 + 域色
    身体：当前计划卡（进度/今日任务/状态灯）
    动作：[开始专注] [编辑机构] [看历史] [新计划]
      │
      ├─ L2 计划面板
      │     周期/频率/休息日/提醒/难度档 + 节点（远征）
      │     动作：[编辑] [暂停] [结算节点]
      │       │
      │       └─ L3 任务面板
      │             类型/目标量/排期/执行方式/最小完成线
      │
      └─ L2' 机构编辑面板
            名称/代号/域色/徽记/口号/停机/归档
```

### 8.3 面板与地图的联动（本方向的核心体验）

| 交互 | 地图侧反应 |
|---|---|
| 打开设施面板 | 自转对齐该设施至屏幕中央偏上；设施放大 1.15×；其他设施降亮度 30% |
| 编辑计划进度条 | 设施上的脚手架同步增减（**实时预览**） |
| 拖拽面板高度 | 镜头轻微后退（面板越高，球体越小），保持设施可见 |
| 新建机构 | 球面出现"选址光标"：可拖到任意空位落地（对应 §三 的 91 个锚位） |
| 删除→归档 | 设施做一次落光动画，然后保留低亮度轮廓（**不消失**，可恢复） |
| 完成任务 | 面板不自动关闭；设施亮一格 + 信号灯变绿，用户自己决定何时关 |

### 8.4 面板的降级形态（低性能/无障碍）

| 场景 | 降级 |
|---|---|
| 低端设备 | 面板不透明背景 + 关闭实时模糊（保留球体可见但不模糊） |
| 无障碍 | 提供"纯列表模式"：所有设施与计划的完整可操作列表（也是"今日列表"副视图的入口） |
| 键盘/桌面 | 设施可用 Tab 遍历，Enter 打开面板；面板支持焦点环 |

## 九、双形态：地图为主 + 今日列表副视图

| | **地图形态（默认）** | **列表形态（一键切）** |
|---|---|---|
| 目的 | 感知积累、空间归属、情绪 | 快速执行、批量勾选、可访问性 |
| 入口 | 冷启动默认 | 顶栏 `4/6` 胶囊 / 底栏「今日」/ 下拉手势 |
| 核心内容 | 星球 + 设施 + HUD | 今日任务清单（按机构分组）+ 快速勾选 |
| 切换方式 | 同一路由内的**视图开关**（不是两个页面），保留滚动位置与筛选 | 同上 |
| 记忆 | 记住上次选择的形态（默认地图，首次进入 7 天内默认地图以建立印象） | — |
| 动效 | 星球向左退出 + 列表从右滑入（320ms），球体转成"列表头图"缩放态 | 反向 |

**为什么保留列表**：地图适合"看"，不适合"5 秒内勾完 4 件事"。日常高频操作必须有一条最短路径，否则地图会变成负担。两者共享同一数据与筛选状态，切换零成本。

## 十、动态星空（远景层）

| 层 | 内容 | 规格 | 与相位的关系 |
|---|---|---|---|
| 天球底 | 程序化星点（10k–20k 星），带视差 | 点尺寸 0.8–2.2 px，颜色按 B-V 色指数偏冷/偏暖 | 相位越暗，亮度越高 |
| 银河带 | 程序化银道带（噪声 + 密度叠加） | 低对比，α ≤ 0.18（`deep` 时 0.28） | 仅 `night`/`deep` 可见 |
| 亮星 | 真实亮星表（约 300 颗，含星座连线开关） | 命名可查（接知识卡体系！） | 常显，日间淡出 |
| 星云/星团 | 少量程序化斑块 | 位置与真实天体对应 | 仅 `deep` |
| 卫星轨线 | 星港自身轨道与若干人造卫星 | 细线 + 移动光点 | 常显 |
| 远景行星 | 一颗远处的伴星/气态行星（地平线上） | 缓慢移动，作为"季节感" | 常显 |
| 极光 | 高纬度相位偶发 | 半透明带 | 与真实地磁活动无关，仅氛围（标注为"氛围效果"，不做伪科学表述） |

**关键联动**：星空中的**真实亮星可点**。点到一个设施"观测到"过的星，会打开对应的知识卡——**背景层因此不是装饰，而是知识体系的入口**。这是"动态星空"唯一值得投入复杂度的理由。

## 十一、性能与耗电预算

| 项 | 目标（中端机，竖屏 1080×2340） |
|---|---|
| 帧率 | 交互时 60fps；`idle` 自转时降到 30fps；后台/熄屏 0fps |
| 单帧耗时 | ≤ 12 ms（60fps），UI 线程 ≤ 4 ms |
| 三角面 | 场景总量 ≤ 15 万（星球 8 万 + 设施 5 万 + 云/大气 2 万） |
| 绘制调用（Draw Call） | ≤ 80（设施合批；同材质实例合并） |
| 纹理内存 | 基础贴图 2048×1024 ≈ 8 MB（压缩后 ≤ 2 MB）+ 设施图集 2048² ≈ 16 MB |
| 内存总量 | 三维场景 ≤ 180 MB |
| 冷启动到首帧 | ≤ 1.2 s（显示静态球体贴图 → 异步补全） |
| 待机耗电 | `idle` 自转 ≤ 4%/小时；进入后台立即停渲染 |
| 热降级 | 设备温度触发 → 自动切"中/低"档 + 自转降频，UI 提示「已切省电渲染」 |

**省电策略**：

| 策略 | 说明 |
|---|---|
| 按需渲染 | 无输入且 `idle` 8 秒后降频；30 秒后停帧（保留 HUD 更新） |
| 材质降级 | 关闭云层 → 关大气 → 降细分 → 静态星空（顺序执行） |
| 合批与实例化 | 设施用 GPU Instancing；同 LOD 同材质合并 |
| 阴影 | **不做实时阴影**（球面光影由光照着色器一次性烘焙进自发光项），仅设施投一个"假影"贴片 |
| 星空 | 用点精灵（point sprite）而非网格；银道带用预生成纹理而非逐帧噪声 |

## 十二、三档渲染与设备分档

| 档 | 判定条件 | 星球 | 设施 | 星空 | 自转 |
|---|---|---|---|---|---|
| **高** | 近 4 年旗舰/次旗舰 | 128×64 + 云 + 大气 + 地块点亮 | L0/L1/L2 三级 | 2 万星 + 银河 + 亮星表 + 星云 | 60fps |
| **中** | 主流中端 | 64×32 + 大气 | L1/L2 | 1.2 万星 + 银河 + 亮星表 | 60/30fps |
| **低** | 老设备/低电/省电模式 | 32×16 + 静态星空贴图 | L2 剪影 | 静态星图（不可点） | 30fps |
| **Web/桌面** | 可访问性优先 | 同"中" | — | — | 60fps |

**低档也必须成立**：低档是"一颗安静的球 + 你的建筑剪影"，信息量依旧完整（谁在营建、谁停机、今天几件）。**任何依赖高画质的核心信息都是设计错误。**
