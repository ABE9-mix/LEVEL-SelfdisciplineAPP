# 三维截图 · 交付说明

> 由 `demo/export-shots.mjs` 自动导出。重跑：
> ```
> node demo/export-shots.mjs
> ```
> 截图源为 `demo/主页面三维演示.html`，通过 Chrome headless + CDP 精确裁切，
> **不是屏幕截图**，所以尺寸是精确像素值，没有窗口边框和系统缩放误差。
> 导出前会调用 `__cam.freeze()` 冻结待机自转并固定转角，**同一次提交的图是确定的**。

## 四、两套机位的取景参数（可复算）

### 4.1 globe 全景（默认 / 待机）

| 项 | 值 |
|---|---|
| 相机距离 | 3.60 R（范围 2.80 – 5.60） |
| 俯角 | 18°（范围 4° – 58°） |
| 球占屏高 | 92%（完整可见，接近满高） |
| 待机自转 | 0.083 rad/s ≈ 76 秒一圈 |

### 4.2 focus 聚焦（点建筑后）

| 项 | 值 |
|---|---|
| 相机距离 | 1.10 R |
| 沿切向后撤 | 0.19 R |
| 光轴俯仰 | +8° |
| 天空占比 | **35.9%**（实测） |
| 建筑屏位置 | 屏幕 x 中央、y ≈ 68%（下三分之一） |
| 建筑屏高 | ≈55 px |

> 参数不是算出来的，是**实测校正**的：按「天空 = 1/3」解析反解得 1.20R，实际只有 22.3%，
> 差在 1.035R 大气壳遮住了地平线上方一条天空。逐档实测后取 1.10R。

## 五、像素规格（设计稿必须知道）

### 5.1 只在整数倍缩放下纯净

| 放置方式 | 结果 |
|---|---|
| **780×454**（原生 @2x） | ✅ 纯三维区板内率 **100%** |
| **1560×908**（2× 最近邻） | ✅ 同样纯净 |
| 390×227（1x） | ⚠️ Figma 双线性会糊掉块边 |
| 任意非整数尺寸 | ❌ 全失 |

**Figma 里正确做法**：用 780 或 1560 版，图片填充选 Fit，框尺寸保持整数倍。

### 5.2 实测数据

| 文件 | 色数 | 板内率 | 天空 |
|---|---|---|---|
| `04` globe 像素化开 | 1,082 | 94.86% | 59.2% |
| `08` focus 像素化开 | 761 | 95.01% | 35.9% |
| `06` ×3 / ×4 / ×6 | 1,084 / 1,098 / 1,140 | 94.85–94.86% | 58.4–58.8% |
| `05` 关闭像素化 | 9,676 | 0.01% | 0% |

> **为什么不是 100%**：三维区改成满幅后，状态栏和标题浮层压在画布上，文字抗锯齿会产生
> 板外过渡色。纯三维区（无 UI 覆盖的部分）实测 100.00%，全图 94.86%。
> 这是「无界三维 + 浮动 UI」这一设计本身的必然结果，不是像素化的缺陷。

## 八、已知限制

| # | 限制 | 说明 |
|---|---|---|
| 1 | 转角是硬编码的 2.4 rad | 想换角度改 `export-shots.mjs` 里的 `setSpin(2.4)` |
| 2 | 设施是**盒体占位**（8 个），不是设计稿的 8 种形制族 | 因相机贴近地表，盒体只露出小方块，效果接近「地表建筑」 |
| 3 | 分段选择器下方是**占位假数据** | 文案非最终内容 |
| 4 | 状态栏手绘（9:41 + 星港），无灵动岛 | — |
| 5 | 透明底版只有「计划」标签 | 需要另两个改编 `export-shots.mjs` 的 `data-k` |
| 6 | 聚焦图只拍了第 4 座建筑 | 想拍别的改 `__cam.focus(3)` 的索引 |
