> ```
> node demo/export-shots.mjs
> ```

## 四、两套机位的取景参数（可复算）

### 4.1 globe 全景（默认 / 待机）

| 项 | 值 |
|---|---|
| 相机距离 | 3.60 R（范围 2.80 – 5.60） |
| 俯角 | 18°（范围 4° – 58°） |
| 球占屏高 | 92%（完整可见，接近满高） |
| 待机自转 | 0.083 rad/s ≈ 76 秒一圈 |

### 4.2 focus 聚焦（点建筑后）

| 项 | 值 |
|---|---|
| 相机距离 | 1.10 R |
| 沿切向后撤 | 0.19 R |
| 光轴俯仰 | +8° |
| 天空占比 | **35.9%**（实测） |
| 建筑屏位置 | 屏幕 x 中央、y ≈ 68%（下三分之一） |
| 建筑屏高 | ≈55 px |

聚焦后还可以**绕建筑环绕**：

| 方向 | 系数 | 满屏拖动 | 手感 |
|---|---|---|---|
| 横向 dx → 方位角 | **−**×0.008 | 390px ≈ 179° | 手指右移 → 画面左移（转动视角） |
| 纵向 dy → 极角 | ×0.004 | 往下拖 = 相机升高 = 更俯视 | 与全景一致 |

### 4.3 过渡（点建筑 → 飞过去）

| 项 | 值 |
|---|---|
| 时长 | **1350 ms** |
| 缓动 | 三次贝塞尔 `cubic-bezier(.42, 0, .58, 1)`，峰值/平均 **1.724** |
| 路径 | 贴着球面的**螺旋**（方向 slerp + 半径插值 + 5% 抬升），按**弧长**取参 |
| 时间线 | 4 条重叠：位置 0–100% / 距离 4–80% / up 2–62% / 看点 10–98% |

实测（逐帧采样）：

| 指标 | 结果 |
|---|---|
| 平滑后峰值/平均 | 最近建筑 1.714、最远 1.689（理论 1.724） |
| 峰值速度 | 3.39 – 4.16 R/s |
| 角位移与半径变化重叠 | **58%**（"绕过去"与"降下去"是一个连续动作） |
| 路径最小半径 | 1.1001 R（未钻 1.035R 大气壳） |
| 星球 | 过渡期带惯性缓停（前 200ms 仍转 0.0049 rad），不再当帧定死 |

| 极角约束 | 值 |
|---|---|
| 下限（防 `lookAt` 与 up 共线） | 22° |
| 上限（防相机钻进 1.035R 大气壳） | 动态 83–88°，实测相机半径 ≥ 1.0500 R |

建筑在任何方位角下都钉在同一屏幕位置（实测转 4.48 rad ≈ 257° 后仍 x=50.0% / y=68.2%），
相机↔枢轴半径恒定 0.2185 R（正圆轨道）。

> 参数不是算出来的，是**实测校正**的：按「天空 = 1/3」解析反解得 1.20R，实际只有 22.3%，
> 差在 1.035R 大气壳遮住了地平线上方一条天空。逐档实测后取 1.10R。

## 五、像素规格（设计稿必须知道）

### 5.0 像素档位对照

| 键 | 块（设备 px） | 网格 | 每格 CSS px |
|---|---|---|---|
| `2` | 2 | 390×227 | 1.0 |
| **`3`** | **3** | **260×151** | **1.5** ← 默认 |
| `4` | 4 | 195×113 | 2.0 |
| `6` | 6 | 130×75 | 3.0 |

> 键位 = 像素边长本身。早期版本用 `PX_LEVELS[+k]` 错位映射，
> 按 `2` 实际取到边长 3，已废弃。

### 5.1 只在整数倍缩放下纯净

| 放置方式 | 结果 |
|---|---|
| **780×454**（原生 @2x） | ✅ 纯三维区板内率 **100%** |
| **1560×908**（2× 最近邻） | ✅ 同样纯净 |
| 390×227（1x） | ⚠️ Figma 双线性会糊掉块边 |
| 任意非整数尺寸 | ❌ 全失 |

**Figma 里正确做法**：用 780 或 1560 版，图片填充选 Fit，框尺寸保持整数倍。

### 5.2 实测数据

| 文件 | 色数 | 板内率 | 天空 |
|---|---|---|---|
| `04` globe 默认档 3px | 1,019 | 94.87% | 59.1% |
| `08` focus home | 776 | 95.01% | 35.8% |
| `09` focus 环绕 | 762 | 95.09% | 36.3% |
| `10` focus 俯视 | 1,499 | 93.90% | 0.0% |
| `06` 块 2 / 4 / 6px | 1,018 / 1,009 / 1,010 | 94.86–94.87% | 58.5–58.8% |
| `05` 关闭像素化 | 9,287 | 0.02% | 0% |

**纯三维区（无 UI 覆盖部分）板内率：四个档位都是 100.00%。**

> **为什么不是 100%**：三维区改成满幅后，状态栏和标题浮层压在画布上，文字抗锯齿会产生
> 板外过渡色。纯三维区（无 UI 覆盖的部分）实测 100.00%，全图 94.86%。
> 这是「无界三维 + 浮动 UI」这一设计本身的必然结果，不是像素化的缺陷。

## 九、重跑方式

```bash
node demo/export-shots.mjs
```

会清空并重写本目录（`design/三维截图/`）。

脚本通过 [`demo/_cdp.mjs`](../demo/_cdp.mjs) 连接浏览器：固定调试端口（9333）+
固定 `user-data-dir`，**跨次复用同一个 headless 实例**，每次跑自动 `Page.navigate`
回到干净状态。**不需要关掉任何 Chrome 进程** —— 早前版本用
`Get-Process chrome | Kill` 清场，那会连你自己开着的浏览器一起杀掉，已废弃。

要彻底清掉这个实例（按 `user-data-dir` 精确匹配，别按进程名杀）：

```powershell
Get-CimInstance Win32_Process -Filter "Name='chrome.exe'" |
  Where-Object { $_.CommandLine -match '--headless' -and $_.CommandLine -match 'xinggang-chrome' } |
  ForEach-Object { Stop-Process -Id $_.ProcessId -Force }
```
